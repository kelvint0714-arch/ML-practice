# Day 3.1：Ridge 怎样从特征形成预测

Ridge 是线性回归加上 L2 正则化。先理解“线性预测”和“限制权重”两个动作，再看类名和参数。

## 1. 线性模型做的加权相加

一个特征时：

```text
预测 = 截距 + 权重 × 特征值
```

两个特征时：

```text
预测 = 截距 + 权重1 × 特征1 + 权重2 × 特征2
```

假设：

```text
截距 = 0.5
权重 = [2.0, -1.0]
输入 = [3.0, 4.0]
```

那么：

```text
预测 = 0.5 + 2.0×3.0 + (-1.0)×4.0 = 2.5
```

“线性”是指预测对当前特征做加权相加。原始对象可能很复杂，例如一个分子可以先被转换成 1024 维 ECFP，再交给线性模型。

## 2. shape 怎样对应

若训练集有 6 个样本、每个样本 1 个特征：

```text
X_train.shape = (6, 1)
y_train.shape = (6,)
coef_.shape   = (1,)
prediction.shape = (6,)
```

若每个样本有 1024 个特征：

```text
X_train.shape = (n_samples, 1024)
coef_.shape   = (1024,)
```

每一列特征对应一个权重；一个样本的 1024 项特征与 1024 个权重逐项相乘后求和。

## 3. 模型从训练数据学什么

调用：

```text
model.fit(X_train, y_train)
```

之后，模型获得：

- `coef_`：每个特征的权重；
- `intercept_`：截距。

这些是模型参数，由训练数据学习。`alpha` 是训练前由人设定的超参数，不是模型从数据自动学到的权重。

名称末尾的 `_` 是 sklearn 常见约定，表示该属性通常要在 `fit` 后才存在。

## 4. 普通线性回归为什么可能不稳定

当以下情况出现时，普通线性回归可能给出很大的正负权重：

- 特征很多而样本较少；
- 多列特征表达相近信息；
- 数据中含有噪声；
- 某些方向几乎没有足够信息。

两个高度相关的特征可能互相“抢功劳”：一个权重很大为正，另一个很大为负，训练预测仍然不错，但数据稍微变化，权重就可能大幅改变。

## 5. Ridge 的目标

直观目标：

```text
训练预测的平方误差
+
alpha × 所有权重平方之和
```

更紧凑地写：

```text
loss = Σ(y_i - ŷ_i)² + alpha × Σ(w_j²)
```

Ridge 通常不惩罚截距，主要压缩各特征权重。

L2 惩罚的作用不是要求所有权重都等于 0，而是让特别大的权重付出更高代价。

## 6. `alpha` 改变权衡

| `alpha` | 对大权重的限制 | 常见风险 |
|---:|---|---|
| 接近 0 | 很弱 | 可能对训练噪声敏感 |
| 适中 | 有所压缩 | 可能改善稳定性 |
| 非常大 | 很强 | 权重过小，欠拟合 |

不能从“有正则化”推出“`alpha` 越大越好”。选择 `alpha` 要看未参与拟合的数据，而不能只看训练误差。

## 7. 为什么观察训练和验证

典型模式：

| 现象 | 可能解释 |
|---|---|
| train 好、valid 差 | 过拟合或数据分布差异 |
| train 与 valid 都差 | 欠拟合或特征信息不足 |
| train 略差、valid 改善 | 正则化可能减少了过拟合 |

这只是诊断信号，不是单凭两行指标就能证明唯一原因。

## 8. 今天暂不引入标准化

L2 惩罚直接作用于系数大小。如果不同特征的数值尺度差异很大，系数大小不能直接公平比较，Ridge 也常与标准化一起使用。

课程在 Day 11 用 `Pipeline` 专门学习“只在训练数据上拟合 scaler”。今天使用同尺度的单特征玩具数据，先把 Ridge 本身看清，避免把多个新概念混在一起。

## 9. 系数不等于因果

一个正系数表示在模型的其他输入保持不变时，该特征增大与预测增大相关。它不自动证明：

- 改变该特征会导致目标变化；
- 该特征是化学机制；
- 不同尺度特征的系数可直接比较；
- 关系在训练范围外仍然成立。

## 10. 今日算法骨架

```text
输入：训练 X、训练 y、预先设定的 alpha
动作：寻找兼顾训练误差与小权重的系数和截距
输出：训练后的线性模型
应用：把验证 X 代入加权和得到预测，再计算指标
```
