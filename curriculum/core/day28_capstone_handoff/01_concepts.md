# Day 28 概念精讲：从课程产物到真实项目门槛

> **重要：v0.3 是空白字段讨论模板。示例行、说明行和空白单元格都不是实验数据，禁止用于训练。**

## 1. 三类产物

### 可公开的课程产物

- 空白 schema；
- 无敏感信息的教程代码；
- 公开 ESOL 方法练习；
- 文献引用与字段讨论。

### 组内受控产物

- 获准使用的处理数据；
- 中间特征、模型和结果；
- 含项目上下文的会议记录。

### 限制数据

- 原始配方；
- 批次和合作方信息；
- 未授权真实性能数据。

权限不清时默认不公开。Git 历史会保留旧版本，先上传再删除不能可靠撤回。

## 2. 结构验收不等于建模验收

打开工作簿并检查列名，只能回答：

- 文件可否读取；
- 预期 sheet 是否存在；
- 关键字段是否出现；
- 模板中有多少非空标签。

它不能证明：

- 字段含义已冻结；
- 单位和测试标准一致；
- 行是独立样本；
- 数据量足够；
- 已取得建模权限。

## 3. 3–5 行真实样例的作用

获准的少量真实样例用于测试接口、单位、必填项、追溯 ID 和缺失原因。它们不足以训练可靠模型，也不能用来展示“初步高分”。

## 4. 首轮建模门槛

在任何 `fit()` 前确认：

1. 体系和首要目标已冻结；
2. 行定义明确；
3. 标签非空且单位/标准可比；
4. 配方、工艺和接头字段含义稳定；
5. 重复/批次关系可用于无泄漏划分；
6. 缺失与异常处理可追溯；
7. 原始数据只读版本已保存；
8. 建模、共享、公开权限分别确认。

任一关键项未通过，应停在数据审计。

## 5. 建模顺序

```text
数据审计
→ 无泄漏划分
→ Dummy / Ridge / RF / Boosting
→ 同协议 MLP
→ 单模型稳定后再考虑 stacking
→ 不确定性诊断
→ 池模拟
→ 化学组审批后才有真实候选
```

复杂度按证据逐级增加。

## 6. GNN 不是默认下一步

只有在具有可用分子结构、合理图定义、足够数据、清楚权限，并且表格基线已稳定时才评估 GNN。粘合剂配方可能包含混合物、工艺和界面条件，不能把一个 SMILES 自动当作完整样本。

## 7. 交接报告的诚信

报告必须分开：

- 已完成：课程、代码、公开数据模拟、schema 讨论；
- 未完成：真实数据训练、真实实验推荐、混合模型项目收益；
- 当前阻塞：体系、字段、样本、权限；
- 下一里程碑及负责人。

不为了“显得有进展”填造数值。
