## 第一步：只做字段评审

请导师与化学组先确认：

1. 体系、行定义与一个首要预测目标；
2. 目标单位、测试标准、配方组分和用量基准；
3. 固化、基材、表面、测试、重复与批次条件；
4. 哪些列可建模、可共享或可公开。

字段确认完成后再形成 v1.0。
不要一边填真实数据一边随意更改列含义。

## 第二步：用 3–5 行真实样例验格式

样例必须是真实且获准使用的记录，
用于检查行定义、单位、必填项、追溯编号和缺失原因。
3–5 行只做接口验收，不足以训练可靠模型。

## 第三步：首批真实数据门槛

开始建模前，必须确认真实标签非空、单位与测试方法一致、
组分及工艺含义稳定、重复和批次关系清楚、数据用途已授权，
并只读保存原始版、记录训练版处理步骤。
样本量是否足够还要结合特征数、重复结构、噪声和验证方法判断。

## 数据权限规则

- 公开：空白 schema、学习代码和无敏感说明可放 GitHub；
- 组内：获准共享的处理数据与结果放受控空间；
- 限制：原始配方、批次和合作方数据放授权存储。

没有明确授权时，真实配方默认不上传 GitHub。
Git 历史会保留旧内容，之后删除文件也不能可靠消除泄露。

## 核心代码：空表结构检查骨架

```python
from pathlib import Path
import pandas as pd

# 从仓库根目录运行这段代码。
workbook = Path(
    "data/adhesive/templates/"
    "粘合剂重要化学性质_数据格式_v0.3.xlsx"
)
raw_sheets = pd.read_excel(workbook, sheet_name=None, header=None)
print("工作表：", list(raw_sheets))

# v0.3 的前三行是标题与填写说明，第 4 行才是字段名。
data = pd.read_excel(
    workbook,
    sheet_name="01_核心化学性质",
    header=3,
)
required_columns = ["样品编号", "粘合剂化学体系", "实测性能名称",
                    "实测性能值", "实测性能单位"]
missing_columns = [
    name for name in required_columns if name not in data.columns
]

print("字段数：", len(data.columns))
print("缺少的关键字段：", missing_columns)
print("数据行数：", len(data))

# 这里只检查结构，不调用任何模型。
assert not missing_columns, "模板结构与任务卡预期不一致"
measured = data["实测性能值"].notna().sum()
print("非缺失实测标签数：", measured)
print("仍需人工确认体系、单位、分组和权限。")
```

## 只解释今天新增的语法

- `Path(...)` 表示一个文件路径。
- `sheet_name=None` 读取全部工作表并返回字典。
- `header=None` 表示暂时不把任何一行当作字段名。
- `header=3` 表示从第 4 行读取正式字段名；Python 从 0 计数。
- 列表推导式按条件找出缺少的关键字段。
- `.notna().sum()` 统计非缺失值数量。
- 结构检查不等于数据已适合训练。

## 分步骤任务：真实数据到达后的建模顺序

1. 冻结原始数据版本。
2. 做单位、缺失、重复和异常审计。
3. 根据配方或批次建立无泄漏划分。
4. 先运行 Ridge、随机森林、梯度提升等基线。
5. 再在同协议下比较 MLP。
6. 只有单模型基线稳定后才测试 stacking。
7. 只有不确定性诊断可接受后才模拟主动学习。
8. 只有化学组审核后才提出真实实验候选。

## 常见错误

| 错误 | 后果 | 正确处理 |
|---|---|---|
| 用空表训练 | 没有真实标签 | 停止建模 |
| 把 3–5 行样例当数据集 | 结果无意义 | 只做格式验收 |
| 未授权上传配方 | 数据泄露 | 默认受控存储 |
| 先跑复杂模型 | 无可靠基线 | 传统模型优先 |
| 报告声称实验完成 | 证据不实 | 区分完成与待办 |

没有可靠分子结构、权限不清或表格基线尚未稳定时，
应停留在表格模型；GNN 不是当前任务的必要条件。
