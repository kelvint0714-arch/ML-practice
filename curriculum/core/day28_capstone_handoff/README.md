## 今天为什么学

一组分数不能完整说明模型。结课时需要把任务、数据、划分、基线、选择规则、结果、限制和下一步放进同一份可审计模型卡。

## 核心概念

模型卡回答四类问题：模型做什么、用什么证据评价、在哪些条件下可用、哪些条件下不应使用。所有数字都应能追溯到数据划分和配置。

## 分步骤任务

1. 冻结任务和主要指标；
2. 汇总 Dummy、传统模型、MLP 和混合模型；
3. 只依据验证证据说明模型选择；
4. 单独列出测试结果，不用它继续调参；
5. 写出限制、失败模式和不适用范围；
6. 形成下一步学习或复现计划。

## 核心代码

~~~python
model_card = {
    "task": "regression",
    "primary_metric": "rmse",
    "selection_split": "cross_validation",
    "test_used_for_selection": False,
    "limitations": [],
}
~~~

## 常见错误

- 只报告最佳数字，不报告 Dummy；
- 用 test 选择模型后又把 test 称为最终评价；
- 隐藏波动、失败运行或额外输入；
- 把验证集领先写成普遍优越；
- 模型卡没有版本和日期。

## 完成标准

- [ ] 任务、输入、目标和指标明确；
- [ ] 每个模型使用相同评价口径；
- [ ] 有 Dummy 和简单基线；
- [ ] 结果包含波动或逐折证据；
- [ ] 限制和不适用范围具体；
- [ ] 下一步不是简单增加模型复杂度。

## 自测问题

1. 为什么模型卡不能只写模型结构？
2. test_used_for_selection 为什么应为 False？
3. 验证领先可以支持什么结论？
4. 模型获得额外输入时怎样报告？
5. 下一步应由哪个证据缺口决定？
