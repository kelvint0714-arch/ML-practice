## 核心概念

### 1. 本课程中的“张量”

“张量”可以泛指具有零个或多个维度的数值数组。
今天直接使用 NumPy：

| 名称 | 示例形状 | 含义 |
|---|---:|---|
| 标量 | `()` | 一个数 |
| 向量 | `(4,)` | 四个数 |
| 矩阵 | `(4, 3)` | 四个样本、三个特征 |
| 三维数组 | `(2, 4, 3)` | 两批、每批四个样本、三个特征 |

### 2. MLP 的基本形状

如果输入 `X` 是 `(4, 3)`，第一层权重 `W` 是 `(3, 2)`：

```text
(4, 3) @ (3, 2) → (4, 2)
```

中间两个 `3` 必须相同；结果保留外侧的 `4` 和 `2`。

### 3. 偏置广播

形状 `(2,)` 的偏置可以加到 `(4, 2)` 的每一行。
这种自动扩展叫广播，不是复制出一个新模型。

## 核心代码骨架

```python
import numpy as np

X = np.array([
    [1.0, 0.0, 2.0],
    [0.5, 1.0, 1.5],
    [2.0, 1.0, 0.0],
    [1.5, 0.5, 1.0],
])
y = np.array([1.2, 0.8, 1.5, 1.1])

W = np.array([
    [0.2, -0.1],
    [0.4, 0.3],
    [-0.2, 0.5],
])
b = np.array([0.1, -0.1])

hidden_linear = X @ W
hidden_with_bias = hidden_linear + b
y_column = y.reshape(-1, 1)

print("X:", X.shape)
print("W:", W.shape)
print("X @ W:", hidden_linear.shape)
print("after bias:", hidden_with_bias.shape)
print("y:", y.shape)
print("y column:", y_column.shape)

assert X.shape[0] == y.shape[0]
assert X.shape[1] == W.shape[0]
assert hidden_with_bias.shape == (4, 2)
```

## 只解释今天新增的语法

- `X @ W` 中的 `@` 表示矩阵乘法，不是逐元素相乘。
- `shape[0]` 是第一维，通常表示样本数。
- `shape[1]` 是第二维，通常表示特征数或隐藏单元数。
- `reshape(-1, 1)` 保留总元素数并变成一列，`-1` 让 NumPy 自动推断行数。
- `(4, 2) + (2,)` 使用广播，把偏置加到每个样本。

## 常见错误

| 错误 | 现象 | 检查 |
|---|---|---|
| 把样本和特征维颠倒 | 矩阵乘法失败或含义错误 | 先写 `(样本, 特征)` |
| 把 `*` 当成 `@` | 得到逐元素结果或广播错误 | 明确需要哪种乘法 |
| `y` 长度与样本数不同 | 训练时报不一致 | 检查 `X.shape[0]` |
| 为消除报错随意 reshape | 形状能跑但语义错 | 先解释每一维 |
| 以为张量必须来自 PyTorch | 额外安装依赖 | 今天只用 NumPy |
