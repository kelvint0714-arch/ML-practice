# Day 15 算法推演：逐层追踪 shape

## 1. 定义输入语义

设四个样本、三个特征：

```text
行：样本
列0：特征 A
列1：特征 B
列2：特征 C
```

因此：

```python
X.shape == (4, 3)
```

标签：

```python
y.shape == (4,)
```

第一维都为 4，说明数量一致；仍需保证行顺序真正对齐。

## 2. 第一层权重

希望把三个输入特征变成两个隐藏单元：

```text
W.shape = (3, 2)
```

手算输出：

```text
(4, 3) @ (3, 2) → (4, 2)
```

第一行第一隐藏单元：

```text
X[0, 0] * W[0, 0]
+ X[0, 1] * W[1, 0]
+ X[0, 2] * W[2, 0]
```

## 3. 加偏置

两个隐藏单元各有一个偏置：

```text
b.shape = (2,)
```

```python
Z = X @ W + b
```

`Z.shape` 仍为 `(4, 2)`。

## 4. 标签列向量

```python
y_column = y.reshape(-1, 1)
```

`-1` 让 NumPy 根据总元素数推断行数，因此：

```text
(4,) → (4, 1)
```

若输出预测为 `(4, 1)`，与 `y_column` 相减得到 `(4, 1)`。若预测为 `(4, 1)` 却与原始 `y (4,)` 相减，则广播为 `(4, 4)`，这是特别危险的静默错误。

## 5. 故意制造矩阵乘法错误

```python
bad_W = np.zeros((4, 2))
X @ bad_W
```

尝试：

```text
(4, 3) @ (4, 2)
```

内侧 `3` 和 `4` 不相等，因此失败。修复方法不是随意 reshape `X`，而是先确认权重第一维应该等于输入特征数 3。

## 6. 建立 shape 地图

| 名称 | shape | 轴 0 | 轴 1 |
|---|---:|---|---|
| `X` | `(4, 3)` | 样本 | 输入特征 |
| `y` | `(4,)` | 样本 | — |
| `W` | `(3, 2)` | 输入特征 | 隐藏单元 |
| `b` | `(2,)` | 隐藏单元 | — |
| `Z` | `(4, 2)` | 样本 | 隐藏单元 |
| `y_column` | `(4, 1)` | 样本 | 输出 |

把这张表写在代码前，可以让矩阵乘法从“试到不报错”为止，变成可预测的设计。

## 7. 三组自检

结构检查：

```python
assert X.ndim == 2
assert y.ndim == 1
```

对齐检查：

```python
assert X.shape[0] == y.shape[0]
```

运算检查：

```python
assert X.shape[1] == W.shape[0]
assert (X @ W + b).shape == (4, 2)
```
