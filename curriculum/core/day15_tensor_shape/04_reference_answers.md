## B. 手算题

7. 依次为：

```text
X @ W1       → (32, 64)
+ b1         → (32, 64)
@ W2         → (32, 1)
+ b2         → (32, 1)
```

8. 示例：

```text
X = [1, 2]
W = [[3, 4],
     [5, 6]]
b = [0.5, -0.5]

X @ W = [1×3 + 2×5, 1×4 + 2×6] = [13, 16]
结果 = [13.5, 15.5]
```

9. NumPy 从最右维对齐：`(4, 1)` 与 `(4,)` 被视为 `(4, 1)` 与 `(1, 4)`，广播后输出 `(4, 4)`。
10. 可以理解为 2 个批次、每批 4 个样本、每样本 3 个特征；这只是人为赋予的语义。
