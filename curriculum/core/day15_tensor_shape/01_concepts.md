# Day 15 概念讲义：张量与 shape

## 学习目标

今天只使用 NumPy，不安装 PyTorch。完成后你应能：

- 从 `.shape` 读出每一维的语义；
- 区分标量、向量、矩阵和三维数组；
- 在运行前判断矩阵乘法输出形状；
- 解释偏置广播；
- 区分 `(n,)` 与 `(n, 1)`；
- 理解“形状正确”不等于“科学含义正确”。

## 1. 张量先理解成多维数字数组

| 名称 | NumPy 示例 | shape | `ndim` |
|---|---|---:|---:|
| 标量 | `np.array(3.0)` | `()` | 0 |
| 向量 | `np.array([1, 2, 3])` | `(3,)` | 1 |
| 矩阵 | `np.zeros((4, 3))` | `(4, 3)` | 2 |
| 三维数组 | `np.zeros((2, 4, 3))` | `(2, 4, 3)` | 3 |

“张量”描述维度结构，不自动说明每一维代表什么。研究者必须为轴赋予语义。

## 2. 监督学习中的常见形状

对单目标表格回归：

```text
X.shape = (n_samples, n_features)
y.shape = (n_samples,)
```

例如：

```text
X.shape = (902, 1024)
```

表示 902 个样本、每个样本 1024 个特征。

```text
y.shape = (902,)
```

表示 902 个标量标签。逗号不是“右边空了一维”，而是 Python 单元素元组语法；`(902)` 只是整数 902，`(902,)` 才是 shape 元组。

## 3. `(n,)` 与 `(n, 1)`

二者元素数相同，但维度不同：

| shape | 解释 |
|---|---|
| `(n,)` | 一维向量，常用于 sklearn 单目标 `y` |
| `(n, 1)` | 二维列矩阵，常用于显式矩阵计算 |

转换：

```python
y_column = y.reshape(-1, 1)
y_again = y_column.ravel()
```

危险点：`(n,) - (n, 1)` 会广播成 `(n, n)`，不会自动报错。因此 shape 错误不总是以异常出现，有时会静默产生错误结果。

## 4. 矩阵乘法规则

```text
(a, b) @ (b, c) → (a, c)
```

内侧维度必须相同，输出保留外侧维度。

若：

```text
X:  (4, 3)
W1: (3, 2)
```

则：

```text
X @ W1 → (4, 2)
```

四个样本都被映射成两个隐藏单元。

## 5. `@` 与 `*`

- `@`：矩阵乘法，按行列求点积；
- `*`：逐元素乘法，并遵守广播规则。

```python
A = np.ones((2, 3))
B = np.ones((3, 4))
A @ B       # 合法，结果 (2, 4)
A * B       # shape 不兼容，报广播错误
```

两数组 shape 恰好相同时，`A * B` 能运行，但它仍不是矩阵乘法。

## 6. 偏置广播

隐藏线性输出为 `(4, 2)`，偏置为 `(2,)`：

```text
(4, 2) + (2,) → (4, 2)
```

NumPy 从最右侧维度对齐，把两个偏置值分别加到每个样本的两个隐藏单元上。概念上像把偏置重复四行，但通常不需要手工创建重复矩阵。

## 7. shape 断言

```python
assert X.ndim == 2
assert y.ndim == 1
assert X.shape[0] == y.shape[0]
assert X.shape[1] == W1.shape[0]
```

断言把预期写成可执行条件，适合在进入长训练前尽早失败。

## 8. 形状正确仍可能语义错误

下面两种错误可能 shape 完全相同：

- 特征列顺序被打乱；
- `y` 行顺序与 `X` 不对齐；
- 温度单位从 °C 误当成 K；
- 一行从“一个配方”变成“一个重复测量”，却未更新分组设计。

所以 shape 是必要检查，不是数据质量和科学意义的充分证明。
