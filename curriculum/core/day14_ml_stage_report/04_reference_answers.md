# Day 14 练习参考答案

## A. 审计题

1. 数据、样本含义、特征、标签、单位/尺度、划分、模型参数、指标实现、seed/折数、软件环境和源文件路径，任取至少八项。
2. 两者来自不同评价协议与样本角色，统计量含义不同；直接平均会产生没有明确解释的混合数。
3. 标签缩放改变数值单位，RMSE 也随之改变。
4. 停止报告生成并修复或重新运行源实验；不能静默按四折汇总后与其他五折模型比较。
5. 先确认真实源结果与计算逻辑，再重新生成或修正文档。不能为了让文档一致而篡改源数据。

## B. 结构题

6. 可采用“研究问题、数据、目标、特征、划分协议、候选模型、结果、观察、能力边界、缺失证据、下一步”。
7. 示例：

- 证据：逐折 CSV 有 25 行且每模型 5 折。
- 解释：某折较差可能与样本分布有关，尚未验证。
- 决定：下一阶段在相同折协议下建立 MLP 教学基线。
- 边界：人工数据结果不代表 ESOL 或下游任务。

8. 可以得出流程是否运行、当前折上的相对表现、折间观察波动；不能得出普遍最优、新骨架泛化或真实下游任务性能。
9. 参考讲义中的清单，并根据本人实际进度增删。
10. MLP 是待评价的新候选；公平实验要求在看结果前保持开放，不预设胜负。

## C. 代码题

11. 对同一批样本，RMSE 通常不小于 MAE。失败时先检查指标是否同一行样本、是否恢复负号、是否有 NaN、列是否错位。
12. 示例：

```python
expected = {1, 2, 3, 4, 5}
assert fold_metrics.groupby("model")["fold"].apply(
    lambda s: set(s) == expected
).all()
```

13. 审计应通过 `np.isfinite(...)` 失败并抛出错误。
14. 示例：

```python
summary["delta_rmse_vs_dummy"] = (
    summary["rmse_mean"]
    - summary.loc[summary["model"] == "dummy", "rmse_mean"].iloc[0]
)
```

15. 两列可以填真实相对路径和准确协议名，例如 `synthetic_kfold5_tutorial`。
