# Day 1.3：先读懂伪代码

伪代码用接近自然语言的方式表达算法步骤，不要求符合 Python 语法。

它的作用是把两个问题分开：

1. 算法要做什么；
2. Python 应该怎样写。

## 单个模型的流程

```text
准备训练输入 X_train
准备训练答案 y_train
准备验证输入 X_valid
准备验证答案 y_valid

创建一个尚未训练的模型
让模型用 X_train 和 y_train 学习
让训练后的模型对 X_valid 产生预测
比较预测值与 y_valid
计算 MAE、RMSE 和 R²
解释结果能够说明什么、不能说明什么
```

对应关系：

| 伪代码动作 | Python 中以后会看到 |
|---|---|
| 创建模型 | `model = SomeModel(...)` |
| 用训练数据学习 | `model.fit(X_train, y_train)` |
| 对验证输入预测 | `prediction = model.predict(X_valid)` |
| 计算评价指标 | `metric(y_valid, prediction)` |

## 多个候选算法的流程

```text
提前确定要比较的候选算法

对每个候选算法：
    创建模型
    只使用训练数据学习
    对训练数据预测
    对验证数据预测
    分别记录训练指标和验证指标

使用同一个验证指标公平比较
检查训练与验证之间是否差距过大
暂时不打开测试集
保存全部候选结果，而不是只保留最好结果
```

这里的“对每个候选算法”以后通常会写成 Python 的 `for` 循环。但现在先确保你能口头复述流程。
