# Day 1.1：机器学习算法到底在做什么

这一节先不写 Python。目标是先建立“算法地图”，以后每行代码都能放回地图中的某个位置。

## 1. 算法、模型和代码不是一回事

| 名称 | 含义 | 例子 |
|---|---|---|
| 算法 | 从数据中寻找规则的方法 | 决策树算法、随机森林算法 |
| 模型 | 某个算法在具体训练数据上学习后的结果 | 用 ESOL 训练出来的一棵具体决策树 |
| 代码 | 告诉计算机怎样准备数据、调用算法和保存结果 | `model.fit(X_train, y_train)` |

可以把它们类比为：

```text
算法 = 学习方法
训练数据 = 教材和练习题
训练 = 学习过程
模型 = 学习之后形成的判断规则
代码 = 让计算机执行这些步骤的语言
```

创建一个算法对象，不代表它已经学过：

```text
创建模型
≠
完成训练
```

只有把训练数据交给它执行 `fit`，它才会从这批数据中学习。

## 2. 什么是监督学习

监督学习的数据同时包含：

- 输入信息；
- 已知答案。

算法观察许多“输入—答案”示例，再尝试为新输入预测答案。

例如一张**假想的格式示意表**：

| 样本 | 输入信息 | 已知答案 |
|---|---|---|
| 1 | 某个分子的结构表示 | 实测水溶解度 |
| 2 | 另一个分子的结构表示 | 实测水溶解度 |
| 3 | 第三个分子的结构表示 | 实测水溶解度 |

这里没有使用真实粘合剂数据，只是在说明监督学习的格式。

## 3. 什么是回归

如果要预测的答案是连续数值，这类任务叫回归。

例如：

- 水溶解度 `logS`；
- 拉伸强度；
- 剪切强度；
- 玻璃化转变温度；
- 黏度。

“是不是粘合剂”“合格还是不合格”属于类别判断，通常是分类问题，不是回归问题。

Day 1 的 ESOL 练习是回归：

```text
输入：分子的数字表示
输出：预测的 logS 数值
```

## 4. 一行、X 和 y 分别是什么

机器学习数据中：

- 一行通常代表一个样本；
- `X` 表示模型可以看到的输入特征；
- `y` 表示希望模型预测的目标答案。

在 ESOL 中：

| 符号 | 含义 |
|---|---|
| 一行 | 一个分子 |
| `X` | 这个分子的 1024 维 ECFP |
| `y` | 这个分子的实测 `logS` |

所以：

```text
X 不是答案
y 才是答案
```

1024 维 ECFP 也不是 1024 项实测理化性质。它是由分子结构计算得到的数字表示。

## 5. 训练与预测

训练时，算法同时看到训练输入和训练答案：

```text
训练输入 X_train
        +
训练答案 y_train
        ↓
      算法学习
        ↓
    训练后的模型
```

预测时，只把新的输入交给训练后的模型：

```text
新输入 X_new
      ↓
训练后的模型
      ↓
预测值 y_pred
```

模型预测时不能偷看新样本的真实答案。真实答案只用于事后评价预测误差。

## 6. 为什么要分训练、验证和测试

| 数据 | 用途 | 可以做什么 |
|---|---|---|
| 训练集 | 让算法学习 | 调用 `fit` |
| 验证集 | 比较候选方案 | 计算指标、发现过拟合 |
| 测试集 | 最后一次无偏检查 | 方案冻结后才使用 |

如果不断查看测试集并根据它修改算法，测试集就参与了模型开发，不再是一次真正独立的最终检查。

Day 1 只要求记住职责。更严格的数据划分协议会在后面专门学习。

## 7. 五类算法的第一层直觉

现在不用学习公式，只需要知道它们“怎样形成预测”。

| 算法 | 最直观的做法 |
|---|---|
| 均值基线 Dummy | 对所有新样本都预测训练答案的平均值 |
| Ridge | 给不同特征分配权重，再把加权结果相加，同时限制权重不要过大 |
| 决策树 | 连续提出“某个特征是否大于某个值”并把样本分组 |
| 随机森林 | 训练许多不完全相同的树，再把预测取平均 |
| 梯度提升 | 后面的模型依次修正前面模型留下的错误 |

均值基线看起来很简单，但它回答了一个重要问题：

> 复杂模型有没有比“永远猜平均值”更有用？

如果复杂模型连均值基线都无法超过，就不能仅凭“算法名字高级”认为它有效。

## 8. 什么是过拟合

如果模型把训练样本记得非常细：

```text
训练误差很小
验证误差很大
```

它可能只擅长已经见过的数据，没有学到能迁移到新样本的规律。这叫过拟合。

相反，模型在训练集和验证集上都很差，可能是模型过于简单，称为欠拟合。

## 9. 机器学习的固定主线

今后无论学习什么算法，都回到这条主线：

```text
定义问题
→ 明确一行数据、X 和 y
→ 划分数据
→ 用训练集 fit
→ 对未参与训练的数据 predict
→ 计算 MAE、RMSE、R²
→ 检查过拟合和证据边界
```
