# Day 2.1：MAE、RMSE 和 R² 到底在回答什么

这一节先不调用 sklearn。目标是把三个指标和它们回答的问题分开，而不是背三个函数名。

## 1. 评价从“逐个误差”开始

对第 `i` 个样本，先定义：

```text
误差_i = 预测值_i - 真实值_i
```

- 误差大于 0：预测偏高；
- 误差小于 0：预测偏低；
- 误差等于 0：该样本预测正确。

正负误差直接相加会互相抵消。例如 `+2` 和 `-2` 的平均是 0，但模型显然不是没有犯错。因此 MAE 使用绝对值，RMSE 使用平方。

## 2. MAE：典型误差有多大

公式：

```text
MAE = 所有 |预测值 - 真实值| 的平均
```

如果四个绝对误差是：

```text
0.5、0.4、0.8、0.1
```

那么：

```text
MAE = (0.5 + 0.4 + 0.8 + 0.1) / 4 = 0.45
```

MAE 的特点：

- 越小越好；
- 和目标使用相同单位；
- 每增加 1 个单位的绝对误差，贡献就增加 1；
- 容易解释为“每个样本平均错多少”。

如果目标是 `logS`，MAE 的单位也是 `logS`。它不是百分比，除非目标本身就是百分比。

## 3. RMSE：更在意大错误

公式：

```text
RMSE = sqrt(所有 (预测值 - 真实值)² 的平均)
```

平方让大误差的贡献增长更快：

| 绝对误差 | MAE 中的贡献 | RMSE 开平方前的贡献 |
|---:|---:|---:|
| 1 | 1 | 1 |
| 2 | 2 | 4 |
| 4 | 4 | 16 |

RMSE 最后开平方，所以它又回到目标原来的单位。没有开平方的 MSE 则是“目标单位的平方”，解释起来不如 RMSE 直观。

对于同一批样本：

```text
RMSE 通常大于或等于 MAE
```

两者相等通常意味着每个样本的绝对误差都一样。差距越明显，往往说明误差大小越不均匀，可能存在少数大错误；但要确认是哪几个样本，仍需查看误差表。

## 4. R²：相对均值参考改善了多少

R² 比较两个误差总量：

```text
当前模型的平方误差总和
vs
对这批 y_true 永远预测其平均值的平方误差总和
```

可以写成：

```text
R² = 1 - 当前模型平方误差总和 / 均值参考平方误差总和
```

因此：

| R² | 对当前这批被评价样本的含义 |
|---:|---|
| 1 | 预测与真实值完全一致 |
| 0 | 平方误差与数学均值参考相同 |
| 0 到 1 | 比均值参考好 |
| 小于 0 | 比均值参考还差 |

负 R² 是合法结果，不是 Python 自动报错。

### 两个“均值”不要混淆

`r2_score(y_valid, prediction)` 的分母使用当前 `y_valid` 的平均值作为数学参考。实际 Dummy 模型通常只允许从 `y_train` 学习训练均值。训练均值与验证均值可能不同，所以训练均值 Dummy 在验证集上的 R² 可能小于 0。

## 5. 三个指标各自保留了什么信息

| 指标 | 保留方向吗 | 强调大错误吗 | 和目标同单位吗 | 最优方向 |
|---|---|---|---|---|
| 单个 `error` | 是 | 不适用 | 是 | 接近 0 |
| MAE | 否 | 线性计入 | 是 | 越小 |
| RMSE | 否 | 是 | 是 | 越小 |
| R² | 否 | 通过平方误差比较 | 无单位 | 越大通常越好 |

MAE 和 RMSE 都不会告诉你模型整体偏高还是偏低。若要研究方向性，可以另外看平均误差：

```text
mean_error = 所有 (预测值 - 真实值) 的平均
```

它不能替代 MAE，因为正负仍会抵消。

## 6. 指标不能脱离评价数据

一个分数必须同时说明：

- 哪个模型；
- 在 train、validation 还是 test；
- 有多少样本；
- 目标和单位；
- 数据怎样划分；
- 指标怎样计算。

“RMSE 是 1.2”信息不足。更完整的写法是：

> 在固定 ESOL scaffold validation 的 113 个样本上，模型的 RMSE 为某个运行得到的数值，单位是 logS。

本节没有运行 ESOL，因此不要从这里抄出实验数字。

## 7. 极端情况

### 只有一个样本

MAE 和 RMSE 可以计算，但 R² 没有足够的变化作为参考，通常不是有效评价。

### 所有 `y_true` 完全相同

R² 的均值参考平方误差总和为 0，普通的相对比较失去直观意义。此时更应该报告 MAE、RMSE，并说明目标没有变化。

### 含有 NaN 或无穷

指标函数通常会报错或产生不可用结果。计算前应确认：

```text
长度一致、数值有限、目标空间一致
```

## 8. 今日证据边界

四个玩具数字只能证明你会计算和解释指标。它不能证明某个算法适合 ESOL，更不能证明它适合真实粘合剂数据。
