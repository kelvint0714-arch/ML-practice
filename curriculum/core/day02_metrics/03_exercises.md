## A. 方向与单位

对每句话判断“正确/错误”，并写一句理由。

1. RMSE 是回归准确率，越接近 100% 越好。
2. MAE 为 0 表示这批样本上的每个预测都与真实值一致。
3. `logS` 的 RMSE 单位仍是 `logS`。
4. R² 的合法值只能在 0 和 1 之间。
5. 对同一批有限数值，RMSE 不会小于 MAE。
6. 平均误差为 0 就能证明模型没有犯错。
