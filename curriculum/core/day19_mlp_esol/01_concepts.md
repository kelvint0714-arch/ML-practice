# Day 19 概念精讲：把 MLP 放回 ESOL

## 学习目标

完成本节后，你应该能解释：

1. 为什么 MLP 前要标准化；
2. `hidden_layer_sizes=(32,)` 的真实含义；
3. 训练误差与验证误差分别回答什么；
4. 为什么公开 ESOL 的结果不能写成粘合剂结论。

## 1. 今天的输入与输出

ESOL 的每一行代表一个分子。输入 `X` 是 1024 维 ECFP 指纹，目标 `y` 是原始空间中的水溶解度 `logS`。

```text
X_train: (902, 1024)
y_train: (902,)
X_valid: (113, 1024)
y_valid: (113,)
```

`y_train.shape == (902,)` 表示一个包含 902 个标签的一维数组。末尾的逗号是 Python 单元素元组语法，不是“第二维为空”。

## 2. MLP 在做什么

一个隐藏层的回归 MLP 可以写成：

\[
H=\operatorname{ReLU}(XW_1+b_1), \qquad
\hat{y}=HW_2+b_2
\]

- `XW₁+b₁` 把 1024 维输入映射到隐藏空间；
- ReLU 把负值变成 0，保留正值；
- 输出层把隐藏表示压缩成一个连续预测值；
- 训练通过降低均方误差来更新权重。

`hidden_layer_sizes=(32,)` 表示“一个有 32 个神经元的隐藏层”。`(64, 32)` 才表示两个隐藏层。

## 3. 为什么缩放放进 Pipeline

神经网络的优化依赖梯度。如果某些特征数量级远大于其他特征，更新会变得不均衡。ECFP 通常是 0/1 特征，但课程仍使用统一的标准化 Pipeline，目的是学习一个可迁移到连续描述符和真实表格特征的安全流程。

标准化必须只从训练数据学习：

```text
训练：X_train → imputer.fit → scaler.fit → mlp.fit
验证：X_valid → imputer.transform → scaler.transform → mlp.predict
```

若先在全部数据上缩放，验证分布就提前进入了训练过程。

## 4. 四个容易混淆的参数

| 参数 | 控制内容 | 不代表 |
|---|---|---|
| `hidden_layer_sizes` | 隐藏层数量和宽度 | 输入特征数 |
| `alpha` | L2 权重惩罚强度 | 学习率 |
| `learning_rate_init` | 初始更新步长 | 正则化强度 |
| `max_iter` | 最多训练轮数 | 保证运行的轮数 |

`n_iter_` 是拟合后才产生的属性。若它等于 `max_iter`，还要结合收敛警告和损失曲线判断是否需要更多迭代；不能只把警告隐藏掉。

## 5. 怎样读训练—验证差距

- 训练与验证都较差：可能欠拟合、优化失败或特征不足；
- 训练很好、验证明显较差：可能过拟合；
- 两者接近：说明当前流程未出现明显训练—验证断裂，但仍需 Day 21 基线和多划分验证；
- 单次验证更好：只能描述当前协议，不能证明普遍优越。

## 证据边界

今天允许说：

> 在固定 ESOL scaffold 训练/验证划分和 ECFP 输入上，该 MLP 得到了某组实际运行指标。

今天不能说：

- MLP 一定优于传统模型；
- 该分数是最终测试性能；
- 模型已经能够预测或推荐粘合剂；
- ESOL 的 `logS` 等同于粘合强度。
