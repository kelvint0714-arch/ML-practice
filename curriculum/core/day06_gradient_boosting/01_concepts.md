# Day 6.1：Gradient Boosting 怎样顺序修正错误

随机森林让树相对独立地训练后平均。Gradient Boosting 则让模型按顺序成长：后面的树专门学习当前组合模型还没有解决的部分。

## 1. 从一个简单初始预测开始

对于平方误差回归，初始模型常从训练标签均值开始。

训练标签：

```text
[1, 2, 6]
```

初始均值预测：

```text
(1 + 2 + 6) / 3 = 3
```

所以第一轮当前预测是：

```text
[3, 3, 3]
```

## 2. 残差表示还差多少

本课程使用：

```text
residual = y_true - current_prediction
```

上例残差：

```text
[1-3, 2-3, 6-3] = [-2, -1, 3]
```

- 负残差：当前预测偏高；
- 正残差：当前预测偏低；
- 接近 0：当前预测已经接近真实值。

下一棵小树用 `X` 作为输入、用这些残差作为学习目标。

## 3. 新树不是最终预测，而是修正量

若第一棵修正树输出：

```text
[-1.5, -1.5, 3.0]
```

学习率为 0.1，则更新：

```text
new_prediction
= old_prediction + 0.1 × correction
```

得到：

```text
[2.85, 2.85, 3.30]
```

仍然没有一步走到最终答案。后续树继续学习新的剩余错误。

## 4. `learning_rate` 是缩放，不是准确率

| 学习率 | 单棵树修正幅度 | 常见配合 |
|---:|---|---|
| 较小 | 谨慎 | 往往需要更多树 |
| 较大 | 强 | 较少树也能快速拟合，但可能过头 |

学习率与树数量存在配合关系，所以今天先固定两者运行基线。可选观察也只改变学习率，不据此做正式选择。

## 5. `n_estimators` 的同名不同关系

随机森林和 Gradient Boosting 都有 `n_estimators`，但内部关系不同：

| 项目 | 随机森林 | Gradient Boosting |
|---|---|---|
| 第 10 棵树是否依赖前 9 棵 | 通常不直接依赖 | 是 |
| 每棵树学习什么 | 原训练目标 | 当前剩余错误/损失方向 |
| 最终汇总 | 平均树预测 | 初始预测加上逐步修正 |
| 训练是否易于并行 | 相对容易 | 顺序依赖更强 |

相同参数名不代表相同算法。

## 6. 为什么叫“梯度”提升

在一般损失函数下，后续模型学习的是让当前损失下降的方向，也就是负梯度方向。

对于今天使用的平方误差，这个方向与残差紧密对应，所以可以先用“拟合残差”建立直觉。不要把所有损失函数下的 Gradient Boosting 都简化为完全相同的原始残差公式。

## 7. 弱学习器

Boosting 中的单棵树通常较浅，只解决当前错误的一部分：

```text
许多简单修正
→ 叠加成复杂模型
```

若每棵树非常深、学习率又大，组合模型可能很快记住训练噪声。

## 8. 怎样观察顺序学习

sklearn 的 `staged_predict` 可以取得：

```text
加入第 1 棵树后的预测
加入第 2 棵树后的预测
...
加入全部树后的预测
```

把每一阶段的 train/valid RMSE 画出来，可以看到：

- train RMSE 通常持续下降；
- valid RMSE 可能先下降后上升；
- 最后阶段不必然是验证最好阶段。

早停会在 Day 20 系统学习，今天只观察，不做 test 选择。

## 9. Boosting 能修复什么，不能修复什么

它可以逐步拟合复杂非线性关系，但不能自动修复：

- 错误标签；
- 数据泄漏；
- 不合理划分；
- 不含目标信息的特征；
- 与真实应用不同的数据分布；
- 已经被反复用于调参的 test。

## 10. 今日算法骨架

```text
用训练 y 建立初始简单预测
→ 计算当前剩余错误
→ 训练一棵浅树预测修正量
→ 按 learning_rate 缩放并加入总预测
→ 重复 n_estimators 次
→ 在 validation 上评价冻结后的组合模型
```
