## A. shape 题

1. `W1 (10, 8)`、`b1 (8,)`、`W2 (8, 1)`、`b2 (1,)`。
2. `Z1 (20, 8)`、`H1 (20, 8)`、预测 `(20, 1)`。
3. `(8,)` 从右侧与 `(20,8)` 对齐，沿 20 个样本行广播。
4. `H1 @ W2` 失败，因为内侧维度 8 与 7 不一致。

## B. 概念题

5. 线性/仿射变换的复合仍可合并成一次权重矩阵和偏置变换。
6. 负数变 0，0 保持 0，正数保持原值。
7. 不会。还需损失、梯度和参数更新。
8. seed 只让随机数可复现；权重仍未利用标签学习。
9. `H1` 对应列全为 0，该列零值比例为 1。

## C. 手算题

10. 使用讲义参数：

```text
Z1 第1项 = 2×0.5 + (-1)×1.0 + 0 = 0
Z1 第2项 = 2×(-1) + (-1)×0.5 + 0.5 = -2
H1 = [0, 0]
预测 = 0×2 + 0×1 + 0.1 = 0.1
```

11. 一种答案：`X(B,2)`、`W1(2,3)`、`b1(3,)`、`H1(B,3)`、`W2(3,1)`、`b2(1,)`、输出 `(B,1)`。
12. `[[0, 0, 3]]`。

## D. 代码题

13. `W1` 变为 `(输入特征数, 6)`，`b1 (6,)`，`W2 (6, 1)`，中间输出第二维均为 6。
14. 只有 `Z1` 中的负值会导致两种预测不同。
15. 示例：

```python
trace_row = {
    "zero_fraction": float(np.mean(values == 0)),

```

16. 使用 `.copy()` 保存，再用 `np.array_equal` 检查。
17. 若长度与隐藏维不兼容会报广播错误；某些错误长度可能意外广播，因此还应显式断言 `b1.shape == (H,)`。

## E. 表达题

18. 可改为：

> 当前输出来自固定随机权重，只演示前向数据流。与标签偶然接近不代表训练或泛化性能，必须经过优化并在独立验证数据上评价。
