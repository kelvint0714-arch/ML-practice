# Day 16 概念讲义：MLP 前向传播

## 学习目标

今天只计算预测，不训练网络。完成后你应能：

- 画出输入层、隐藏层和输出层；
- 写出权重与偏置 shape；
- 解释线性变换和 ReLU；
- 沿网络追踪中间数组；
- 说明为什么随机权重预测没有性能意义。

## 1. 一个最小两层 MLP

```text
输入 X
  ↓ 线性：Z1 = X @ W1 + b1
隐藏线性值 Z1
  ↓ 激活：H1 = ReLU(Z1)
隐藏表示 H1
  ↓ 线性：Y_pred = H1 @ W2 + b2
预测 Y_pred
```

这里“两层”通常指两组含参数的线性层：输入→隐藏、隐藏→输出；输入本身不算含参数层。

## 2. 参数 shape

设：

```text
批大小 B
输入特征 D
隐藏单元 H
输出维度 O
```

则：

| 数组 | shape | 含义 |
|---|---:|---|
| `X` | `(B, D)` | 一批输入 |
| `W1` | `(D, H)` | 输入到隐藏权重 |
| `b1` | `(H,)` | 每个隐藏单元一个偏置 |
| `Z1` | `(B, H)` | 隐藏层线性值 |
| `H1` | `(B, H)` | 激活后隐藏表示 |
| `W2` | `(H, O)` | 隐藏到输出权重 |
| `b2` | `(O,)` | 每个输出一个偏置 |
| `Y_pred` | `(B, O)` | 预测 |

## 3. 一个隐藏单元在做什么

对第 j 个隐藏单元：

```text
z_j = x_1 w_1j + x_2 w_2j + ... + x_D w_Dj + b_j
```

它把所有输入特征做加权组合，再经过激活函数。多个隐藏单元具有不同权重，因此可以学习不同组合。

## 4. 为什么需要非线性

若没有激活：

```text
(X W1 + b1) W2 + b2
```

可以重新整理成：

```text
X (W1 W2) + 新偏置
```

无论叠多少线性层，整体仍是线性变换。ReLU：

```text
ReLU(z) = max(0, z)
```

把负值截为零、正值保留，引入分段非线性，使网络能表达更复杂关系。

## 5. ReLU 的直觉与限制

| 输入 z | ReLU(z) |
|---:|---:|
| -2.0 | 0.0 |
| 0.0 | 0.0 |
| 1.5 | 1.5 |

ReLU 简单且常用，但并不保证每个单元都活跃。若一个单元对所有样本都输出负 `Z1`，其激活全为零。训练、初始化和学习率会影响这种现象，本日只观察不优化。

## 6. 前向传播不会学习

前向传播只读取当前参数并计算输出：

```python
z1, h1, prediction = forward(X, W1, b1, W2, b2)
```

参数不会自动改变。学习还需要：

1. 用 `y` 计算损失；
2. 求损失对参数的梯度；
3. 按优化规则更新参数；
4. 重复。

这些内容从 Day 17 开始。

## 7. 随机初始化的意义

固定 seed 的小随机权重用于：

- 打破隐藏单元完全对称；
- 让演示可复现；
- 避免初始数值过大。

随机初始化尚未从标签学习，因此随机预测不能与已训练的 Ridge 或随机森林做性能比较。

## 8. 函数应显式接收参数

比起依赖全局变量，更清晰的教学函数是：

```python
def forward(inputs, W1, b1, W2, b2):
    ...
```

输入和输出边界清楚，也便于验证函数不会修改参数。
