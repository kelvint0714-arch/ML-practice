## 核心概念

### 1. 一层不只是一个神经元

隐藏层包含多个隐藏单元。
如果输入有三个特征、隐藏层有四个单元，第一层权重形状就是 `(3, 4)`。

### 2. 线性计算

一层的线性部分可以写成：

```text
Z = X @ W + b
```

`W` 决定输入怎样组合，`b` 提供每个单元的偏移。

### 3. 激活函数

如果每层只有线性计算，多层线性变换最终仍等价于一次线性变换。
ReLU 把负数变成零，保留正数，使网络能够表达非线性关系：

```text
ReLU(z) = max(0, z)
```

### 4. 前向不等于训练

今天的权重由随机数生成，没有根据 `y` 调整。
只有引入损失和优化步骤，网络才会从数据中学习。

## 核心代码骨架

```python
import numpy as np

rng = np.random.default_rng(42)

X = np.array([
    [1.0, 0.0, 2.0],
    [0.5, 1.0, 1.5],
    [2.0, 1.0, 0.0],
    [1.5, 0.5, 1.0],
    [0.0, 1.0, 2.0],
])

W1 = rng.normal(scale=0.2, size=(3, 4))
b1 = np.zeros(4)
W2 = rng.normal(scale=0.2, size=(4, 1))
b2 = np.zeros(1)

def relu(values):
    return np.maximum(0.0, values)

def forward(inputs):
    z1 = inputs @ W1 + b1
    h1 = relu(z1)
    predictions = h1 @ W2 + b2
    return z1, h1, predictions

z1, h1, y_pred = forward(X)

print("z1:", z1.shape)
print("h1:", h1.shape)
print("prediction:", y_pred.shape)

assert z1.shape == (5, 4)
assert h1.shape == (5, 4)
assert y_pred.shape == (5, 1)
```

## 只解释今天新增的语法

- `np.random.default_rng(42)` 创建独立且可复现的随机数生成器。
- `rng.normal(..., size=(3, 4))` 按指定形状生成正态随机数。
- `np.zeros(4)` 创建四个零，作为初始偏置。
- `np.maximum(0.0, values)` 逐元素取较大值，实现 ReLU。
- `return z1, h1, predictions` 一次返回三个对象，左侧用三个变量接收。

## 常见错误

| 错误 | 现象 | 处理 |
|---|---|---|
| `W1` 第一维不等于输入特征数 | 第一层无法相乘 | 对照 `X.shape[1]` |
| `W2` 第一维不等于隐藏单元数 | 输出层无法相乘 | 对照 `h1.shape[1]` |
| 忘记激活函数 | 网络只剩线性组合 | 明确写出 `relu` |
| 认为随机输出是模型结果 | 结论没有训练依据 | 标明仅为前向演示 |
| 为看起来更好而手改权重 | 混淆演示与训练 | 下一天再学习优化 |
