# Day 16 算法推演：手算一个前向过程

## 1. 设置极小网络

一个样本、两个输入、两个隐藏单元、一个输出：

```text
X  = [[1.0, 2.0]]                shape (1, 2)
W1 = [[ 0.5, -1.0],
      [ 1.0,  0.5]]              shape (2, 2)
b1 = [0.0, 0.5]                  shape (2,)
W2 = [[2.0],
      [1.0]]                     shape (2, 1)
b2 = [0.1]                       shape (1,)
```

## 2. 第一层线性计算

第一个隐藏单元：

```text
1.0 × 0.5 + 2.0 × 1.0 + 0.0 = 2.5
```

第二个隐藏单元：

```text
1.0 × (-1.0) + 2.0 × 0.5 + 0.5 = 0.5
```

因此：

```text
Z1 = [[2.5, 0.5]]
```

## 3. ReLU

两个值都非负：

```text
H1 = [[2.5, 0.5]]
```

如果第二个 `Z1` 为 `-0.5`，ReLU 后会变成 `0`。

## 4. 输出层

```text
Y_pred = 2.5 × 2.0 + 0.5 × 1.0 + 0.1
       = 5.6
```

输出 shape 为 `(1, 1)`。

## 5. 批量化计算

当 `X` 变成 5 个样本：

```text
(5, 2) @ (2, 2) + (2,) → Z1 (5, 2)
ReLU                         → H1 (5, 2)
(5, 2) @ (2, 1) + (1,) → Y_pred (5, 1)
```

同一组参数对所有行共享。这不是为每个样本训练一套新网络。

## 6. 代码实现

```python
def relu(values):
    return np.maximum(0.0, values)

def forward(inputs, W1, b1, W2, b2):
    z1 = inputs @ W1 + b1
    h1 = relu(z1)
    prediction = h1 @ W2 + b2
    return z1, h1, prediction
```

函数返回中间量，是为了教学追踪。真实库通常把中间状态保存在内部。

## 7. 检查参数未改变

调用前保存副本：

```python
W1_before = W1.copy()
forward(...)
assert np.array_equal(W1, W1_before)
```

若权重没有赋值更新，前向传播应是只读计算。

## 8. 比较有无 ReLU

```python
prediction_relu = relu(X @ W1 + b1) @ W2 + b2
prediction_linear = (X @ W1 + b1) @ W2 + b2
```

数值可能相同，也可能不同，取决于 `Z1` 是否有负值。这个比较说明激活如何改变信息流，不评价模型好坏。

## 9. 前向 trace 表

建议保存：

| 名称 | shape | 最小值 | 最大值 | 作用 |
|---|---:|---:|---:|---|
| `X` | `(B,D)` | … | … | 输入 |
| `Z1` | `(B,H)` | … | … | 激活前 |
| `H1` | `(B,H)` | … | … | ReLU 后 |
| `Y_pred` | `(B,1)` | … | … | 随机预测 |

表中的数值必须来自已运行输出，不预先编造。
