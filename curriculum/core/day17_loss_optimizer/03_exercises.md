# Day 17 练习：损失与优化

## A. 概念题

1. 为什么直接平均带正负号的误差可能互相抵消？
2. 参数更新式为什么通常有减号？
3. 学习率过小和过大分别可能出现什么？
4. 训练损失下降是否证明验证 RMSE 也下降？
5. 损失与论文报告指标必须完全相同吗？
6. `inf` 或 `nan` 出现时首先检查哪些内容？

## B. 手算题

7. 对 `x=[0,1]`、`y=[1,3]`、`w=0`、`b=0`，手算 MSE、`grad_w` 和 `grad_b`。
8. 使用学习率 `0.1` 完成一次参数更新。
9. 若梯度为 `grad_w=4` 且学习率为 `0.05`，`w=2` 更新后是多少？
10. 说明为什么更新后必须重新前向，不能继续使用旧误差。

## C. 代码题

11. 分别运行学习率 `0.001`、`0.05` 和 `0.5`，画在同一张对数 loss 图中。
12. 为运行函数加入 `record_every` 参数，只控制日志频率，不改变更新次数。
13. 写有限差分代码检查第 0 步 `grad_w`。
14. 故意把更新减号改为加号，保留前几步输出并解释。
15. 增加提前停止：若 loss 非有限则停止，并记录 `status="diverged"`。
16. 检查日志每行的 loss 是否确实由同一行 `w,b` 计算，而不是更新前后错位。

## D. 边界题

17. 训练 loss 从 21 降到很小，可以得出什么、不能得出什么？
18. 为什么本日的一元线性模型与 MLP 有共同主线，但不等于完整 MLP？
19. 改写错误说法：

> 学习率越大，模型学得越快，所以应该尽可能大。
