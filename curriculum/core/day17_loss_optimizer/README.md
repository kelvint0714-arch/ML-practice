## 核心概念

### 1. 损失函数

均方误差 MSE 把每个误差平方后求平均：

```text
MSE = mean((prediction - y)²)
```

损失是训练过程要减小的目标，不是论文中唯一应该报告的指标。

### 2. 梯度

梯度表示“参数稍微变化时，损失朝哪个方向变化得最快”。
沿梯度相反方向更新，通常能够让当前批次的损失减小。

### 3. 学习率

学习率控制每一步移动多远：

- 太小：下降很慢；
- 合适：损失逐步下降；
- 太大：可能震荡或发散。

### 4. 优化器

优化器负责根据梯度更新参数。
今天手写的是最基础的梯度下降；后面 `MLPRegressor` 会内部执行更完整的优化。

## 分步骤任务

1. 创建一个很小的 `x` 和 `y`。
2. 把权重 `w` 和偏置 `b` 初始化为零。
3. 写出预测公式 `x * w + b`。
4. 计算误差和 MSE。
5. 计算 `w`、`b` 的梯度。
6. 用学习率更新两个参数。
7. 每十步记录一次损失。
8. 分别尝试较小和较大的学习率。
9. 不改变数据来“帮助”损失下降。
10. 说明训练损失不能替代验证指标。

## 核心代码骨架

```python
import numpy as np

x = np.array([0.0, 1.0, 2.0, 3.0])
y = np.array([1.0, 3.0, 5.0, 7.0])

w = 0.0
b = 0.0
learning_rate = 0.05
history = []

for step in range(51):
    prediction = x * w + b
    error = prediction - y
    loss = np.mean(error ** 2)

    grad_w = 2.0 * np.mean(error * x)
    grad_b = 2.0 * np.mean(error)

    w -= learning_rate * grad_w
    b -= learning_rate * grad_b

    if step % 10 == 0:
        history.append({
            "step": step,
            "loss": float(loss),
            "w": float(w),
            "b": float(b),
        })

for record in history:
    print(record)

assert np.isfinite(w)
assert np.isfinite(b)
```

## 只解释今天新增的语法

- `error ** 2` 表示逐元素平方。
- `w -= value` 等价于 `w = w - value`，它确实修改了 `w`。
- `step % 10 == 0` 使用取余数，表示每十步记录一次。
- `np.isfinite(...)` 检查结果不是缺失值或正负无穷。
- `history` 只用于记录，不参与参数更新。

梯度公式今天先理解作用，不要求独立完成微积分推导。

## 常见错误

| 错误 | 现象 | 处理 |
|---|---|---|
| 沿梯度正方向更新 | 损失快速增大 | 更新式前使用减号 |
| 学习率过大 | 数值震荡或变成无穷 | 降低学习率 |
| 更新前后混用同一个损失 | 记录含义不清 | 明确每条记录对应哪一步 |
| 训练损失下降就宣布成功 | 没有泛化证据 | 后续检查验证集 |
| 用完整 MLP 公式硬推导 | 负担过大 | 先掌握一参数例子 |
