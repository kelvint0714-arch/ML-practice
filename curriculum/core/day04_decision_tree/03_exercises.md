## A. 手算叶节点预测

一个叶节点包含训练标签：

```text
[2, 3, 7]
```

1. 回归树在这个叶节点输出多少？
2. 三个训练样本在该叶中的平方误差分别是多少？
3. 平方误差总和是多少？
4. 如果把标签 7 单独切到另一个叶，两个叶的训练平方误差总和变成多少？
5. 为什么这不能自动证明这次切分会改善验证表现？

## B. 比较两个候选阈值

数据：

| x | y |
|---:|---:|
| 0 | 0 |
| 1 | 0 |
| 2 | 4 |
| 3 | 4 |

分别手算：

- 不切分时的平方误差总和；
- 在 `x <= 0.5` 切分后的平方误差总和；
- 在 `x <= 1.5` 切分后的平方误差总和；
- 哪个候选对训练数据更好。
