# Day 4.1：决策树怎样切分，又为什么会过拟合

决策树不做一条全局加权直线。它反复提出阈值问题，把样本分组，最后在每个叶节点给出局部预测。

## 1. 一棵回归树像一组嵌套规则

只有一个特征时，一棵小树可能表示：

```text
如果 x <= 2.5：
    如果 x <= 1.0：预测 0.8
    否则：预测 2.1
否则：
    预测 4.7
```

每个样本从根节点开始，根据条件走左或右，直到叶节点。

## 2. 节点、分裂和叶节点

| 术语 | 作用 |
|---|---|
| 根节点 | 包含全部训练样本的起点 |
| 内部节点 | 提出一个特征阈值问题 |
| 分支 | 条件为真或假时前往的路径 |
| 叶节点 | 不再切分并输出预测的位置 |
| 深度 | 从根向下经历的层级 |

回归树的叶节点通常预测落入该叶的训练标签平均值。

例如某个叶节点含有：

```text
y = [2.0, 2.5, 3.0]
```

该叶的预测是：

```text
(2.0 + 2.5 + 3.0) / 3 = 2.5
```

## 3. 算法怎样选择一次分裂

对许多候选“特征＋阈值”，算法比较切分后的平方误差。直观过程：

```text
尝试候选阈值
→ 把训练样本分到左右两组
→ 每组用自己的标签均值预测
→ 计算两组总平方误差
→ 选择能最大程度降低误差的切分
```

只允许使用训练标签选择切分。验证标签不能参与建树。

## 4. 手算一个候选阈值

训练样本：

| x | y |
|---:|---:|
| 0 | 0 |
| 1 | 1 |
| 2 | 4 |
| 3 | 5 |

若阈值为 `x <= 1.5`：

- 左叶标签 `[0, 1]`，预测 0.5；
- 右叶标签 `[4, 5]`，预测 4.5。

切分后平方误差总和：

```text
(0-0.5)² + (1-0.5)² + (4-4.5)² + (5-4.5)² = 1.0
```

不切分时所有样本预测总均值 2.5：

```text
(0-2.5)² + (1-2.5)² + (4-2.5)² + (5-2.5)² = 17.0
```

这个候选分裂让训练平方误差明显下降。

## 5. 树为什么能表达非线性

线性模型在一个特征上形成一条直线；回归树形成分段常数：

```text
一个区域预测一个值
另一个区域预测另一个值
```

不断增加切分后，树可以拟合弯曲、阶梯或特征交互。但灵活性越大，也越容易记住训练数据的偶然细节。

## 6. 深树怎样记住离群点

如果训练集中某一个标签异常高，深树可以围绕它建立很窄的区域，让该样本单独进入一个叶节点。

结果可能是：

```text
训练误差几乎为 0
验证误差却变大
```

这不是模型“学得特别好”，而可能是把异常记住了。

## 7. 控制复杂度的两个旋钮

### `max_depth`

限制从根向下最多生长多少层：

- 小：规则少，可能欠拟合；
- 大：规则多，可能过拟合；
- `None`：不显式限制深度，不是深度为 0。

### `min_samples_leaf`

规定每个叶节点至少包含多少训练样本：

- 小：允许很小的局部区域；
- 大：叶预测由更多样本平均，通常更平滑；
- 过大：也可能欠拟合。

今天固定 `min_samples_leaf`，只改变 `max_depth`。

## 8. 训练—验证差距是信号，不是裁决

若训练 R² 很高而验证 R² 很低，过拟合是合理怀疑。但差距还可能受以下因素影响：

- validation 很小；
- train 与 validation 分布差异大；
- 存在标签噪声；
- 划分偶然性。

因此正确说法是“结果表现出过拟合信号”，而不是“已经证明唯一原因是树深”。

## 9. 树的外推限制

回归树的预测来自训练叶节点中的标签汇总。对于远超训练范围的新输入，它通常不会像线性模型那样沿斜率继续外推，而是停留在边界叶的常数预测。

如果任务需要预测训练范围外的性质，这一点必须单独检查。

## 10. 今日算法骨架

```text
训练数据进入根节点
→ 搜索降低训练平方误差的切分
→ 递归切分，直到达到停止条件
→ 每个叶节点保存训练标签均值
→ 新样本沿规则走到叶节点并得到预测
```
