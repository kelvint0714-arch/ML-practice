# Day 26 概念精讲：候选池主动学习模拟

## 1. 三个互斥区域

| 区域 | 特征可见 | 标签可见 | 用途 |
|---|---:|---:|---|
| 已标注集 | 是 | 是 | 训练模型 |
| 候选池 | 是 | query 前否 | 选择下一批 |
| 固定外部对照集 | 是 | 仅评价时 | 在同一口径下比较本轮更新 |

候选池不能同时充当外部对照集，否则揭示并加入训练后，评估边界会移动。
本教程使用 ESOL valid；它没有参与 Day 25 的采集规则诊断，也不进入候选池，
但在课程更早阶段已经被查看过，所以不能称为严格未见的最终 test。

## 2. 一轮循环

```text
已标注集训练集成
→ 只读取 X_pool 生成预测与分歧
→ 固定 query_ids
→ 模拟/真实实验返回 selected_y
→ 更新已标注集
→ 在固定外部 valid 上按同一口径比较
```

代码中应有清楚的“标签揭示线”。在该线之前不允许引用 `y_pool`。

## 3. 主动策略为何需要随机对照

新增标签本身通常会改善模型。只有与相同初始集、相同预算、相同评估集和相同重复次数的随机选择比较，才能讨论主动选择是否提供额外价值。

一次主动策略胜过一次随机策略不够。本教程只验证单轮接口；
正式策略研究应预先固定多个初始化种子和轮数，并报告完整学习曲线。

## 4. 采集分数

本课程用集成标准差：

\[
a(x)=\operatorname{std}\{\hat y_1(x),...,\hat y_M(x)\}
\]

它只依赖候选特征和冻结模型预测。真实项目还应在排序前或之后加入由领域团队定义的可行性约束，但不能让候选真实性能参与。

## 5. 池模拟不是实验

在公开 ESOL 中，`y_pool` 其实已经存在，只是代码在 query 前隐藏它。揭示标签模拟“实验返回”，不能写成真正合成、测试了新分子或新下游任务。

## 6. 真实交接

算法组输出的候选表至少包括：

- 候选唯一编号；
- 配方/工艺字段（真实项目才有）；
- 模型预测与启发式分歧；
- 选择轮次和模型版本；
- 化学可行性状态与禁止原因。

领域团队返回目标值、单位、标准、重复次数、批次、实际配方偏差和失败记录。未经批准，算法排名不是实验指令。

## 7. 决策边界

单轮模拟差异可能依赖 ESOL 特征、池构成和初始种子。它不能证明真实下游任务主动学习有效；作用是验证无标签泄漏的接口和同预算对照协议。
