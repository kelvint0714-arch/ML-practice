# Day 22 练习

## A. 分类题

将下列方案分类为特征级、预测级或残差式结合：

1. 把 RDKit 描述符与配方比例拼接后训练 RF；
2. 用 Ridge 和 MLP 的两列预测训练第二层；
3. 先拟合冻结随机森林，再让 MLP 学 `y - pred_RF`。

## B. 泄漏定位

解释下列每种做法的泄漏路径：

1. 在全部 train+valid 上选出与 `y` 相关性最高的 20 列；
2. 用全训练拟合 RF，并用 RF 的训练预测训练第二层；
3. 将同一配方的三个重复试样随机拆到不同折；
4. 看过 test 后决定是否开启 `passthrough`。

## C. 手工 OOF

有样本编号 0–5，其 group 依次为 `[A, A, B, B, C, C]`，使用 3 折：

```text
fold 1 holdout: [0, 1]
fold 2 holdout: [2, 3]
fold 3 holdout: [4, 5]
```

对每一折写出训练编号，并说明样本 3 的二层输入由哪个模型产生。
再写出一条代码断言，证明每折训练 group 与 holdout group 互斥。
