## 核心概念

### 1. 特征级结合

把两类已知输入特征拼在一起，再训练一个模型。
例如配方数值特征与分子描述符结合。

前提是两类特征都能在预测新样本时获得，
而且特征提取器不能用验证标签学习。

### 2. 预测级结合

多个基础模型分别预测，
第二层模型学习如何组合这些预测。
这通常称为 stacking。

第二层训练时必须看到基础模型对“未参与其训练样本”的预测，
也就是折外预测 OOF。

### 3. 残差式结合

先让传统模型预测主要趋势，
再让第二个模型学习真实值与第一模型预测之间的残差。

残差模型训练时使用的第一阶段预测也必须是 OOF 预测，
否则残差会显得不真实地容易学习。

## 只解释今天新增的术语

- “基础模型”是先产生预测的第一层模型。
- “第二层模型”接收基础模型预测，并学习如何组合。
- “OOF”是某个样本由没有训练过该样本的模型产生的预测。
- “残差”通常写成 `真实值 - 第一阶段预测值`。
- “预注册方案”表示运行前先写好比较方法和失败条件。
- “训练内预测”是模型对自己训练过的样本做的预测，通常过于乐观。
- “组互斥”表示同一 group 不能同时出现在某一折的 fit 与 holdout 中。

## 泄漏风险清单

| 风险 | 泄漏路径 | 防止方法 |
|---|---|---|
| 全数据缩放 | 验证分布进入训练 | 每折内部拟合 Pipeline |
| 全数据特征选择 | 验证标签影响选列 | 每折内部完成选择 |
| 训练内预测做二层输入 | 标签被基础模型记忆 | 使用 OOF 预测 |
| 用验证结果不断改方案 | 验证集变相参与训练 | 预先限定方案 |
| 同一配方重复落入不同折 | 近重复样本互相泄漏 | 按配方或批次分组 |

## 粘合剂项目中特别危险的泄漏

同一配方的重复试样不应随机分散到训练与验证。
同一批次、同一基材或同一次实验中的高度相关记录，
可能需要使用 GroupKFold 或按时间划分。

这些分组字段必须由化学组提供，
算法不能只凭数值相似度猜出真实实验关系。

如果结构特征由公开数据库补充，
还要记录查询日期、来源和缺失处理，
不能让目标性能参与特征补全。

## 常见错误

| 错误 | 表面现象 | 实际问题 |
|---|---|---|
| 在全训练集拟合后预测全训练集 | 二层训练分数可能异常好 | 二层看到过度乐观输入；外部方向不保证 |
| stacking 一定比单模型好 | 结构更复杂 | 没有理论保证 |
| 同时换特征和模型 | 分数变化 | 无法判断收益来源 |
| 忽略重复实验关系 | 验证分数很好 | 可能是组间泄漏 |
| 先看测试再决定结构 | 测试“最好” | 测试集已被选择污染 |
