# Day 22 概念精讲：结合方式与泄漏路径

## 1. 三种结合方式

### 特征级结合

把预测时可获得的两组输入横向拼接，例如：

```text
[配方特征 | 固化条件 | 分子描述符] → 一个模型
```

风险在于某些特征可能由全数据或标签导出。特征提取和选择也必须位于训练折内部。

### 预测级结合

基础模型分别输出预测，第二层学习组合：

```text
X → 树模型 ─┐
             ├→ [pred_tree, pred_mlp] → meta model → final prediction
X → MLP ────┘
```

第二层训练输入必须是 OOF 预测。

### 残差式结合

模型 A 先学主趋势，模型 B 学 `y - pred_A`。模型 B 训练时使用的 `pred_A` 也必须是 OOF，否则残差会被不真实地压小。

## 2. 泄漏的本质

泄漏不是“代码报错”，而是训练过程取得了未来预测时不应拥有的信息。
它通常会让训练或验证表现显得过度乐观，但在具体外部样本上偏差方向并不保证。

常见路径：

- 在全数据上填补、缩放、选特征；
- 用基础模型对自己训练样本的拟合预测训练第二层；
- 同配方重复试样跨折；
- 根据外部验证反复改结构；
- 查看测试结果后重新选择方案。

## 3. 为什么训练内预测危险

高容量基础模型可能几乎记住训练标签。若第二层看到这种训练内预测，它学到的输入质量远高于真实新样本时的输入质量。训练阶段与部署阶段因此不一致。

OOF 预测恢复了更接近部署的条件：每个训练样本都由没见过它的基础模型预测。
若存在重复配方或批次，还必须保证产生该预测的模型也没见过同组样本。

## 4. 简单平均为什么重要

简单平均没有可学习的第二层：

\[
\hat y_{\text{mean}}=(\hat y_A+\hat y_B)/2
\]

它便宜、透明、不需要 OOF 来估计组合权重。若复杂 stacking 不能稳定超过它，就应质疑复杂度是否必要。

## 5. 分组泄漏

真实粘合剂数据中，一行可能是同一配方的重复试样。随机 KFold 可能把近重复行分到不同折，使模型“认出配方”。应由化学组提供配方、批次或实验组标识，再决定 GroupKFold 或时间划分。Day 22 的合成 group 只用于练习索引检查，不能冒充真实业务分组。

不能仅凭数值相近自己编造组号，也不能把 ESOL 的 molecule ID 当作真实粘合剂批次。
