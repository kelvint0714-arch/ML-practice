# Day 5.1：随机森林为什么需要“有差异的树”

随机森林不是把同一棵树复制很多遍。它主动让不同树看到不同样本、考虑不同特征，再平均预测。

## 1. 一棵树的问题：高方差

决策树很灵活。训练数据稍微变化，一个阈值就可能变化，后续整片分支也随之改变。

这类现象可以直观称为高方差：

```text
换一小部分训练样本
→ 学到的具体树结构变化很大
→ 新样本预测也可能明显波动
```

限制树深可以降低复杂度；随机森林采用另一个思路：让多棵有差异的树共同决定预测。

## 2. Bootstrap：每棵树看到不同训练样本

原始训练编号：

```text
[0, 1, 2, 3, 4]
```

有放回抽取 5 次可能得到：

```text
[1, 1, 4, 0, 4]
```

特点：

- 抽取次数与原训练样本数相同；
- 同一编号可以出现多次；
- 某些编号可能一次都没有出现；
- 每棵树使用独立的随机抽样。

这叫 Bootstrap 样本。

## 3. 随机特征：每次切分不看所有列

假设输入有 100 个特征。若每棵树、每个节点都从全部特征中选择同一个极强特征，不同树可能仍然非常相似。

随机森林会在每次寻找切分时，只考虑随机抽到的特征子集。`max_features` 控制这个子集大小。

随机特征的目的不是丢弃数据，而是降低树与树之间的相似性。

## 4. 为什么差异很重要

如果 100 棵树完全相同：

```text
每棵都预测 3.2
平均后仍然是 3.2
```

若树的误差不完全同步：

```text
树1：2.8
树2：3.3
树3：3.5
平均：3.2
```

某些偏高与偏低可能相互抵消，平均预测通常比单棵高方差树稳定。

“树有差异”还不够；每棵树也需要有一定预测能力。许多完全随机且没有信息的模型平均，仍然不会成为好模型。

## 5. Bagging 的算法骨架

```text
重复 n_estimators 次：
    从训练集有放回抽样
    训练一棵树
    每次切分随机考虑部分特征

预测时：
    每棵树对同一样本预测
    将所有树预测取平均
```

回归任务使用平均；分类随机森林常汇总类别概率或投票。今天只讨论回归。

## 6. 关键超参数分别控制什么

| 参数 | 控制对象 | 不是什么 |
|---|---|---|
| `n_estimators` | 树的数量 | 树深 |
| `max_depth` | 每棵树的最大深度 | 树数量 |
| `min_samples_leaf` | 每个叶最少样本数 | Bootstrap 次数 |
| `max_features` | 每次切分考虑的特征数/比例 | 总输入维数 |
| `bootstrap` | 是否有放回抽样 | 随机种子 |
| `random_state` | 固定伪随机过程 | 提高准确率的参数 |

## 7. 树越多会怎样

增加树数量通常会：

- 增加训练和预测时间；
- 增加内存占用；
- 让随机平均逐渐稳定；
- 但不保证验证误差持续下降。

如果每棵树都受到同样的数据偏差或特征不足，增加树数不能自动消除这些系统性问题。

## 8. 随机森林也会过拟合吗

会。平均通常降低单树方差，但以下设置仍可能带来风险：

- 样本极少；
- 树很深、叶很小；
- 标签噪声大；
- 特征泄漏；
- 为验证集反复调参；
- 数据划分不符合应用场景。

随机森林不是“不会过拟合”的安全开关。

## 9. 随机性与复现

同一配置若不固定 `random_state`，Bootstrap 和随机特征选择可能变化，结果也可能变化。

学习阶段先固定种子，保证代码问题和随机波动不会混在一起。后续 Day 10 会用多个种子量化稳定性。

## 10. 特征重要性的边界

树模型可以提供特征重要性，但它不能自动证明：

- 特征与目标存在因果关系；
- 相关特征中被选中的那一列就是唯一机制；
- 高基数或连续特征的默认重要性没有偏差；
- 在新数据分布中仍然重要。

今天不使用特征重要性下化学结论。
