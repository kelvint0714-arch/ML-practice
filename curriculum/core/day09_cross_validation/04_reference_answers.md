# Day 9 练习参考答案

参考答案用于核对思路，不是唯一措辞。

## A. 概念题

1. 5 折需要拟合 5 个彼此独立的新模型；每个样本恰好当一次折内验证样本。
2. 第 1 折模型已经学习过第 2 折中部分样本。继续训练会让当前验证样本不再“未参与拟合”，发生折间状态泄漏。
3. 不能。K 折用于训练区域内部的方案开发；最终测试集必须留到方案冻结后再按协议使用。
4. 不足。还应保存每折原始分数、均值、标准差、折样本数和折生成配置。第 4 折的 `1.8` 是不能被平均值隐藏的重要证据。
5. 相似骨架可能跨越训练折和验证折，模型面对的是“相似分子”而非真正的新骨架。
6. 验证折可能通过训练折中的同配方重复样本获得近乎重复的信息，成绩偏乐观。

## B. 纸笔题

7. 一种不打乱的分法是：

```text
折1验证：[0, 1, 2, 3]
折2验证：[4, 5, 6, 7]
折3验证：[8, 9, 10, 11]
```

每轮 8 行训练、4 行验证。

8. 两个误差分别为 `-1`、`1`，平方误差都是 `1`：

```text
RMSE = sqrt((1 + 1) / 2) = 1
```

9. 不能完全相同。scikit-learn 会让前若干折多一行，各折大小最多相差 1。
10. 合格图示例如：

```text
全部可用数据
├── 训练区域 → 折1/折2/折3/折4/折5轮流验证
└── 外部测试集 → 封存，不进入 cv.split
```

## C. 代码题

11. 核心检查：

```python
validation_counts = np.zeros(len(X), dtype=int)
for _, valid_ids in cv.split(X):
    validation_counts[valid_ids] += 1
assert np.all(validation_counts == 1)
```

12. 可在记录字典中加入：

```python
fold_record = {
    "valid_y_mean": float(y[valid_ids].mean()),
}
```

若难折的目标均值或范围明显不同，只能把它视为调查线索，不能仅凭均值断定原因。

13. 一种写法：

```python
assert set(fit_ids).isdisjoint(set(valid_ids))
```

14. `shuffle=False` 时没有随机打乱动作，因此 `random_state` 没有可控制的随机过程。scikit-learn 要求删除它，避免配置看起来生效但实际无意义。
15. 示例：

```python
from sklearn.model_selection import GroupKFold

group_cv = GroupKFold(n_splits=5)
for fit_ids, valid_ids in group_cv.split(X, y, groups):
    assert set(groups[fit_ids]).isdisjoint(set(groups[valid_ids]))
```

## D. 研究表达题

16. 可改为：
