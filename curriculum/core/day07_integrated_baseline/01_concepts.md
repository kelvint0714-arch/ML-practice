# Day 7.1：完整 Notebook 中哪些是算法，哪些是工程

前六天的最小代码只有几行。完整 ESOL 基线有 10 个代码单元，因为可复现实验不仅要训练模型，还要说明数据、环境、边界和输出从哪里来。

## 1. 算法主线没有变

无论 Notebook 多长，核心仍是：

```text
准备 X 与 y
→ 创建候选模型
→ fit(X_train, y_train)
→ predict(X_valid)
→ metric(y_valid, prediction)
```

找不到主线时，不要从第一行开始背。先搜索：

```text

.fit(
.predict(
regression_metrics
```

## 2. 工程支持为什么必要

| 工程任务 | 防止什么问题 |
|---|---|
| 查找仓库根目录 | 输出保存到错误位置 |
| 固定缓存目录 | 数据散落或重复下载 |
| 记录版本 | 不同环境难以复现 |
| 固定随机种子 | 随机结果无从核对 |
| 检查 shape/有限值 | 错误输入悄悄进入模型 |
| 检查 ID 重叠 | 同一样本跨 split |
| 保存参数与指标 | 只剩截图，无法审查 |
| 断言测试集未使用 | 开发阶段偷看 test |

这些代码不是新的预测算法，但它们决定实验结果是否可信。

## 3. Notebook 内核是有记忆的

执行一个代码单元会把变量保留在内存中。若先运行第 8 格，再修改并运行第 3 格，第 8 格的旧结果不会自动更新。

危险情况：

```text
今天打开昨天的内核
→ 前面数据单元没有运行
→ 后面单元仍使用旧变量
→ 表面成功，实际不可复现
```

可靠验证：

```text
Restart Kernel
→ Run All
→ 执行号从 1 连续到 10
→ 无 error output
→ 最后一格断言通过
```

## 4. 保存的输出不是本次运行

`.ipynb` 可以保存旧的表格、图和执行号。打开时看见数字，只证明文件里存着输出，不证明你当前环境刚刚重跑成功。

个人记录应写：

- 重跑日期；
- 使用的环境；
- 是否从空内核；
- 是否有 traceback；
- 执行号是否连续；
- 工作树是否干净；
- 产物是否重新生成。

## 5. warning、traceback 与断言

### warning

提醒潜在问题，执行可能继续。要阅读内容并判断是否影响当前路径，不能一律忽略。

### traceback

异常调用链。当前单元没有完成，后续旧输出不能继续当作有效结果。

### `AssertionError`

代码主动检查的条件不成立。例如预期 split 无重叠却发现交集。它属于应停止调查的失败，不是“多点几次运行”能解决的问题。

### 普通输出

`print`、表格和进度信息不是错误。

## 6. 数据、特征和目标口径

当前参考基线：

| 项目 | 固定设置 |
|---|---|
| 数据 | ESOL / Delaney |
| 一行 | 一个分子 |
| 特征 | 1024 维 ECFP，radius=2 |
| 目标 | 原始 `logS` |
| 划分 | scaffold |
| split 大小 | 902 / 113 / 113 |
| 开发评价 | train 与 validation |
| test | 本轮不产生新预测 |

`transformers=[]` 很重要：指标位于原始 `logS` 空间。不同目标变换下的数值不能直接混在一张表比较。

## 7. 五个固定候选的角色

| 模型 | 角色 |
|---|---|
| Dummy mean | 最低参照 |
| Ridge | 线性基线 |
| 不限深决策树 | 过拟合诊断 |
| 限制决策树 | 正则化树对照 |
| 随机森林 | 固定集成候选 |

这里没有 Day 6 的 Gradient Boosting。课程内容学过一个算法，不等于必须立刻修改历史基线。

## 8. 结果怎样形成

Notebook 对每个候选：

```text
只在 train 上 fit 一次
→ 分别在 train 和 valid 预测
→ 每个模型产生两行结果
```

5 个模型 × 2 个 split = 10 行。按 validation RMSE 排序用于当前固定候选比较，test 不参与。

## 9. 证据边界

当前基线能说明：

- 完整流程可以复现；
- 在一次固定 scaffold validation 上，候选之间存在差异；
- 不限深树表现出训练—验证差距。

它不能说明：

- 当前最好候选对所有划分都最好；
- 已找到 ESOL 最优模型；
- 结果能直接迁移到下游任务；
- 原 test 仍是严格未见；
- GNN 一定更好或更差。
