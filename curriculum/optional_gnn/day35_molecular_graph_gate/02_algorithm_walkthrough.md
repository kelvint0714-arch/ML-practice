# Day 35.2：用门槛表作出 GNN 决策

## 输入、变换、输出

| 项目 | 内容 |
|---|---|
| 输入 | 数据集说明、图结构、标签、划分和基线信息 |
| 变换 | 对七项门槛逐项核对证据 |
| 输出 | 门槛表、决策和下一步 |

## 七项门槛

1. 图对象明确；
2. 节点特征可追溯；
3. 边语义合理；
4. 标签层级与协议明确；
5. 防泄漏划分已定义；
6. 样本量和标签覆盖可评价；
7. 简单基线与输入公平性已记录。

## 决策逻辑

~~~text
如果图对象或边语义不成立：
    No-Go
否则如果标签、划分或基线缺失：
    Conditional Go / No-Go
否则：
    Go
~~~

## 为什么不能自动批准

代码可以检查字段是否存在，但不能替代领域语义判断。字段名叫 edge 不证明关系合理；非空标签也不证明标注协议一致。

## 公平比较计划

至少记录模型、输入集合、参数量、划分、指标、随机种子和训练成本。GNN 与基线应在相同样本和评价点上比较。

## 验收

- 每个门槛有证据而非主观偏好；
- 阻断项与下一步一一对应；
- 没有为了使用 GNN 而构造虚假边；
- 决策可以在证据变化后重新计算。
