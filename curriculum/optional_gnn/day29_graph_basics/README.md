## 核心概念

| 名称 | 小社交图 | 分子图 |
|---|---|---|
| 节点 | 一个人 | 一个原子 |
| 边 | 两个人的关系 | 化学键 |
| 节点特征 | 年龄、类别等 | 元素、价态、电荷等 |
| 边特征 | 关系类型 | 单键、双键、芳香键等 |
| 图标签 | 整个群体的类别 | 整个分子的性质 |

## 核心代码骨架

```python
import numpy as np

nodes = ["A", "B", "C", "D"]
edges = [(0, 1), (1, 2), (2, 3), (0, 3)]

adjacency = np.zeros((len(nodes), len(nodes)), dtype=int)

for source, target in edges:
    adjacency[source, target] = 1
    adjacency[target, source] = 1

print(nodes)
print(edges)
print(adjacency)
```

## 新语法解释

- `[(0, 1), ...]` 是由元组组成的列表；
- `np.zeros((4, 4))` 创建四行四列的全零数组；
- `for source, target in edges` 每次拆出一条边的两个端点；
- `adjacency[source, target] = 1` 表示两个节点相连；
- 无向图同时写反方向，所以矩阵通常关于对角线对称。

## 常见错误

- 只写一个方向，却把图说成无向图；
- 把节点特征矩阵误认为邻接矩阵；
- 把一个节点的标签误认为整张图的标签；
- 看到矩阵就认为已经包含化学键类型。
