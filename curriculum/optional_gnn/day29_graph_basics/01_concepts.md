# Day 29.1：图数据的五个基本对象

今天的重点不是背 GNN 名称，而是先回答：一张图到底由什么组成？

## 1. 图是什么

一张图可以写成：

```text
图 = 节点集合 + 边集合 + 可选的特征与标签
```

本日使用四个节点：

```text
A、B、C、D
```

以及四条无向边：

```text
A—B、B—C、C—D、D—A
```

它们组成一个四边形。节点只是对象，边说明对象之间存在连接。

## 2. 节点、边、特征与标签

| 名称 | 本日玩具图 | 分子图中的可能含义 |
|---|---|---|
| 节点 | A、B、C、D | 原子 |
| 边 | A—B 等连接 | 化学键 |
| 节点特征 | 每个节点的两个数值 | 元素、价态、电荷等编码 |
| 边特征 | 本日没有使用 | 键类型、芳香性等编码 |
| 整图标签 | 本日没有用于训练 | 某个分子性质 |

“可能含义”不等于已经拥有可靠分子数据。真实项目仍需确认结构来源、建模对象、配方关系和实验标签。

## 3. 节点编号不是节点特征

为了让数组定位节点，可以编号：

```text
A → 0
B → 1
C → 2
D → 3
```

编号只是位置索引。节点 3 不一定比节点 1 “更大”，也不意味着它具有更强的化学性质。

节点特征是另一个数组：

```python
import numpy as np

node_features = np.array(
    [
        [1.0, 0.0],
        [0.0, 1.0],
        [1.0, 1.0],
        [0.5, 0.5],
    ],
    dtype=float,
)
```

它的 `shape` 是 `(4, 2)`：

- 4 行：4 个节点；
- 2 列：每个节点有 2 个特征；
- 第 `i` 行属于编号为 `i` 的节点。

## 4. 无向边为什么涉及两个方向

边 `A—B` 表示 A 与 B 相连。用编号写是 `(0, 1)`。

如果用矩阵记录连接，就要同时标记：

```text
从 0 看见 1
从 1 看见 0
```

因此无向边 `(0, 1)` 会让邻接矩阵的两个位置变成 1：

```text
adjacency[0, 1] = 1
adjacency[1, 0] = 1
```

这不是两条不同的化学键，而是同一条无向边在两个方向上的记录。

## 5. 邻接矩阵

本日图的邻接矩阵是：

```text
      A  B  C  D
A     0  1  0  1
B     1  0  1  0
C     0  1  0  1
D     1  0  1  0
```

矩阵形状为 `(4, 4)`，因为行和列都在枚举 4 个节点。

读法示例：

- `adjacency[0, 1] == 1`：A 与 B 相连；
- `adjacency[0, 2] == 0`：A 与 C 没有直接相连；
- 对角线为 0：本日没有让节点连接自己；
- 矩阵对称：本日图是无向图。

邻接矩阵只表达本日的“是否相连”。它没有表达键类型，也没有自动包含节点特征。

## 6. 度数与邻居

节点的度数是它连接了多少个邻居。本日每个节点都有两个邻居，所以：

```text
degree = [2, 2, 2, 2]
```

在 NumPy 中：

```python
degree = adjacency.sum(axis=1)
```

`axis=1` 表示保留每一行，沿着列的方向把该行元素相加。输入 `adjacency.shape == (4, 4)`，输出 `degree.shape == (4,)`。

## 7. 消息传递的最小直觉

先把每个节点的特征理解为它准备发送的“消息”。节点 A 的邻居是 B 和 D，所以 A 收到：

```text
B 的特征 + D 的特征
= [0.0, 1.0] + [0.5, 0.5]
= [0.5, 1.5]
```

所有节点可以一起计算：

```python
neighbor_message_sum = adjacency @ node_features
```

shape 变化：

```text
(4, 4) @ (4, 2) → (4, 2)
```

输出仍然每个节点一行，但这一行现在是邻居特征之和。

## 8. 这还不是 GNN

本日计算只有固定的求和：

- 没有可学习权重；
- 没有损失函数；
- 没有反向传播；
- 没有训练集、验证集和测试集；
- 没有预测任务。

真正的 GNN 会在消息聚合前后加入可学习变换，并通过数据训练参数。今天只建立消息传递所需的数据结构直觉。

## 9. 今日证据边界

这张四节点图只能证明你理解图的表示与邻居求和。它不能证明：

- GNN 比传统机器学习更好；
- 本项目已经有可用的分子结构；
- 单个分子图足以表示多组分粘合剂配方；
- 玩具特征具有化学意义。
