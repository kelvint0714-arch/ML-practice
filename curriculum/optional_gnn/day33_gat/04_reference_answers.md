# Day 33.4：参考答案

## 练习 1

每头输出宽度 8，四个头沿特征轴拼接：

```text
[34, 8 × 4] = [34, 32]
```

## 练习 2

第一层拼接后每个节点有 32 个特征，第二层却声明只接收 8 个特征，矩阵维度无法相乘。应改为：

```python
GATConv(32, 4, heads=1, concat=False)
```

## 练习 3

- `concat=True`：四个头的输出拼接，宽度为 `8×4=32`；
- `concat=False`：不沿特征轴拼接，输出宽度为 8，多个头的结果按实现规则合并。

## 练习 4

- `attention_edges` 第一行是源节点、第二行是目标节点，190 列代表 190 条参与注意力计算的返回边；
- `alpha` 每一行对应同位置的一条边，两列对应两个注意力头；
- GAT 层默认可能为节点加入自环，所以返回边数可能大于传入的原始边数。

## 练习 5

```python
preview_rows = min(8, attention_edges.shape[1])

attention_preview = pd.DataFrame({
    "source": attention_edges[0, :preview_rows].cpu().numpy(),
    "target": attention_edges[1, :preview_rows].cpu().numpy(),
    "head_0": alpha[:preview_rows, 0].cpu().numpy(),
    "head_1": alpha[:preview_rows, 1].cpu().numpy(),
})
```

不排序是因为目标只是认识返回张量结构，不挑选“最高权重”并据此编写重要性故事。

## 练习 6

逻辑缺口包括：

- 权重来自特定模型、层、头、输入和随机种子，可能不稳定；
- 高聚合权重不等于删除该边会造成最大预测变化；
- 模型内部关联不等于现实因果关系；
- 未做干预、对照或独立验证；
- 还需要确认比较的是哪个目标节点邻居集合中的归一化权重。

## 练习 7

它回答“在当前不等训练预算下，这两个具体训练结果如何”，但没有隔离图算子差异，也不能回答“相同训练预算时哪个模型表现更好”。公平比较应保持 epoch 相同，或预先定义对所有模型一致的停止规则。

## 练习 8

不能直接归因于注意力，因为模型参数量和内部结构同时变化。更谨慎：

> 在固定 KarateClub validation 协议与三种配对种子下，当前 GAT 配置的平均结果较高，同时其参数量也不同。该教学实验不能把差异单独归因于注意力机制，需进一步做容量控制、更多重复和独立 test。

## 练习 9

test 必须独立于模型选择。现在仍在根据 validation 比较结构、理解模型并可能修改代码；提前查看 test 会让后续决策受到 test 影响。只有模型、超参数、随机种子汇总方式和报告规则全部预先冻结后，才能进行一次最终 test 评价。
