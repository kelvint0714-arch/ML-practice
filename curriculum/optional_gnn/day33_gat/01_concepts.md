# Day 33.1：图注意力、多头 shape 与解释边界

## 1. 为什么引入注意力

GCN 按归一化规则聚合邻居；mean GraphSAGE 对邻居求平均。GAT 让模型为不同邻居关系计算不同权重。

对目标节点 `i` 和它的一个源邻居 `j`：

```text
节点表示先经过可学习变换
→ 计算 i 与 j 的匹配分数
→ 在节点 i 的所有入邻居之间做 softmax
→ 得到注意力权重 alpha_ij
→ 按 alpha_ij 加权聚合邻居表示
```

同一目标节点、同一注意力头的邻居权重通常归一化为和接近 1。

## 2. 注意力权重依赖什么

`alpha_ij` 不是输入前固定的常数。它依赖：

- 当前输入节点特征；
- 当前模型学到的参数；
- 图中的邻居集合；
- 训练随机性；
- 若注意力层启用了 dropout 等训练态行为，还会受训练/评价模式影响。

因此同一条边在不同模型种子、不同输入或不同层中可能得到不同权重。

## 3. 多头注意力

一个注意力头学习一套投影与权重。多头可以并行学习多套表示。

设：

- 节点数 `N`；
- 每头输出宽度 `D`；
- 头数 `K`。

当 `concat=True`：

```text
输出 shape = [N, D × K]
```

例如：

```python
GATConv(
    in_channels=34,
    out_channels=8,
    heads=2,
    concat=True,
)
```

输出是 `[N, 16]`，不是 `[N, 8]`。

当 `concat=False` 时，各头不会沿特征轴拼接，输出宽度是 `out_channels`。最终分类层常用 `heads=1, concat=False` 得到 `[N,C]`。

## 4. 本日 GAT 的 shape

```text
x                               [N, F]
GATConv(F, 8, heads=2)       →  [N, 8×2] = [N,16]
ELU                          →  [N,16]
外部 Dropout                 →  [N,16]
GATConv(16, C, heads=1,
        concat=False)         →  [N,C]
```

三类模型都使用隐藏表示总宽度 16：

| 模型 | 第一层输出 |
|---|---|
| GCN | `[N,16]` |
| GraphSAGE | `[N,16]` |
| GAT | `[N,8×2] = [N,16]` |

这控制了表示宽度，但参数量仍可能不同。

## 5. 为什么 GAT 使用 ELU

ELU 是一种非线性激活：

- 正数区域接近线性；
- 负数区域平滑趋近一个下界；
- GAT 经典实现常使用 ELU。

本日 GCN/SAGE 使用 ReLU，GAT 使用 ELU，这是各自预先声明的固定模型结构。它意味着比较并非“除单个算子外所有数学操作完全一致”，因此结论仍需谨慎。

## 6. `return_attention_weights`

PyG 的 `GATConv` 可以返回输出和注意力信息：

```python
hidden, (attention_edges, alpha) = gat_layer(
    x,
    edge_index,
    return_attention_weights=True,
)
```

典型 shape：

```text
hidden             [N, D×K]
attention_edges    [2, E_attention]
alpha              [E_attention, K]
```

`E_attention` 可能大于原始 `edge_index.shape[1]`，因为 `GATConv` 默认可能加入自环。不要假设返回边与原始边一一同序。

`alpha[row, head]` 表示返回的第 `row` 条边在某个注意力头中的权重。

## 7. 为什么只显示少量权重

完整图可能有很多边和多个头。直接打印全部权重：

- 难以阅读；
- 容易淹没关键输出；
- 会诱导读者从大量数字中挑选一个故事。

本日只显示前 8 条返回边：

```python
attention_preview.head(8)
```

“前 8 条”只是有界结构预览，不是权重最高的 8 条，也不是最重要的 8 条。

## 8. 注意力为什么不是因果解释

高注意力权重只能说明：

> 在这个模型、这次训练、这个输入和这一层中，该边在该头的归一化权重较大。它对最终消息的实际贡献还取决于变换后特征向量的大小与方向。

它不能自动说明：

- 删除这条边必然导致预测显著变化；
- 该边是现实机制的原因；
- 该邻居在所有随机种子中都重要；
- 在分子中对应“决定性质的化学键”。

因果结论需要干预设计、对照实验、领域验证和稳定性分析。即使做遮蔽或删除边的敏感性实验，也通常只能得到模型层面的干预证据，不等于现实因果机制。
