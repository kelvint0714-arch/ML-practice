# Unit 07 概念精讲：模型、表示和不确定性分工

## 1. RF

适合表格描述符、小中型数据。树或模型集成分歧可提供启发式不确定性。

## 2. MLP

学习非线性表格映射。普通单个 MLP 只给点预测；可用深度集成、MC Dropout 或贝叶斯方法扩展。

## 3. GNN/MPNN

输入节点、边和图结构。它可以：

- 直接预测分子/材料性能；
- 输出 embedding，再交给 GP/RF；
- 组成多个模型的集成估计分歧。

只有存在可靠 SMILES、晶体或分子图时才有结构基础。

## 4. PBNN

部分贝叶斯神经网络只将部分权重概率化，用后验采样产生预测分布，尝试降低完整 BNN 的成本。

PBNN 与 GP 首先是**概率代理模型**；后验样本或后验标准差才是供采集函数
使用的不确定性信号。不能把整个模型简单归入“不确定性模块”。

## 5. DKL

```text
高维输入 → 神经网络 embedding → GP → 均值与后验方差
```

神经网络负责表示，GP 负责概率回归。两部分通常联合训练。

## 6. 模型委员会

DP-GEN 使用多个深度势模型对原子构型的预测分歧选择 DFT 标签。这属于主动/并发学习，但不是 EI/UCB 型 BO。

## 7. 公平比较

先固定研究问题：

- 若比较代理模型，采集函数不变；
- 若比较表示，后端模型尽量不变；
- 若比较不确定性，平均预测能力和计算成本也要报告。
