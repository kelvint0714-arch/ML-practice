## 核心概念

- 代理模型近似昂贵 Oracle；
- 认知不确定性来自有限数据，理论上可随新标签减少；
- 偶然不确定性来自实验或过程噪声，不能仅靠多训练几个模型消除；
- 集成标准差是启发式分歧，需校准实验才能获得概率含义。

## 分步骤任务

1. 在相同初始点上训练 GP。
2. 用 GP 输出候选均值和后验标准差。
3. 训练多个不同种子的 RF 成员。
4. 对 RF 成员预测求均值和标准差。
5. 比较两种模型的排序，不强求数值相同。
6. 两个一次性 query 都固定、campaign 结束后，才由 evaluator 使用整池隐藏标签诊断误差。
7. 写出不确定性局限。

## 核心代码骨架

```python
gp_mean, gp_std = gp.predict(X_pool, return_std=True)

rf_matrix = np.vstack([
    member.predict(X_pool) for member in rf_members
])
rf_mean = rf_matrix.mean(axis=0)
rf_disagreement = rf_matrix.std(axis=0)
```

## 常见错误

| 错误 | 后果 | 正确处理 |
|---|---|---|
| 将两种 std 当成同一统计量 | 解释错误 | 写清来源 |
| 用池标签挑模型 | 泄漏 | 只在训练内部验证 |
| std 大就声称误差必大 | 过度结论 | 做校准/相关诊断 |
| 复杂模型无基线 | 无法判断价值 | 保留简单 GP/RF |
