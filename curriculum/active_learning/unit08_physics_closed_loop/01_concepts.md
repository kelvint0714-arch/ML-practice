# Unit 08 概念精讲：物理知识怎样进入主动学习

## 1. 作为输入特征

把组成、温度、固化度或计算描述符加入 \(X\)。这是最简单方式，但模型不一定遵守物理规律。

## 2. 作为均值或核

结构化 GP 用物理模型作为均值，GP 学残差；也可设计反映周期性、距离或对称性的核。

## 3. 作为约束

相图、配比、能量稳定性和设备窗口可过滤候选或修改采集函数。

## 4. 作为 Oracle/多保真来源

低成本模拟、DFT、PINN 或经验模型可先提供近似标签，高成本实验提供高保真标签。多保真主动学习还需建模不同来源偏差。

## 5. 真实闭环架构

CAMD 使用：

```text
Agent → Experiment → Analyzer → Campaign
```

CAMEO 将材料结构知识用于真实 XRD 选点；DP-GEN 用多个神经网络分歧选择 DFT 构型。

## 6. PINN 的位置

PINN 用 ODE/PDE、边界条件和数据训练过程代理。只有再定义候选、采集函数、Oracle 和回填循环，才进入主动学习系统。

## 7. Human-in-the-loop

安全、可制备性和设备判断不能由教学模型自动越权。每条推荐都应带版本、理由、状态和审核记录。
