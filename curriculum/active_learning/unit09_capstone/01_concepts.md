# Unit 09 概念精讲：从课程机制到研究证据

## 1. 可重现

同一代码、数据版本、配置和随机种子可以得到一致结果。可重现不等于结论正确，但不可重现的结果无法检查。

## 2. 忠实复现与统一重实现

- 忠实复现：尽量保持论文数据、代码、环境和指标；
- 统一重实现：在相同接口、预算和基线下跨论文公平比较。

两者必须分开记录，不能把重写代码结果当作原论文结果。

## 3. 最小基线

- Random；
- Greedy 或简单 uncertainty；
- 简单 GP/RF；
- 论文原方法；
- 关键模块开/关消融。

## 4. 证据等级

```text
教学人工数据
→ 公开数据离线回放
→ 多公开材料数据统一基准
→ 模拟/DFT 闭环
→ 小规模真实实验
→ 独立重复和外部验证
```

顶刊或顶会结论通常需要算法新意、强基线、多任务证据和清楚消融；真实材料影响还需要实验验证。

## 5. 数据与代码边界

论文 PDF 和第三方代码按许可使用；真实合作数据按授权存储。GitHub 中的课程、配置和公开复现记录不能无意暴露真实配方。
