# 主动学习标签泄漏检查表

## Query 固定之前

- [ ] 训练函数只接收 `X_labeled`, `y_labeled`
- [ ] 候选预测函数只接收 `X_pool`
- [ ] 采集函数不接收 `y_pool`
- [ ] 没有使用候选绝对误差或真实排名
- [ ] 没有根据候选真实结果调整 `beta`、`xi` 或 batch size
- [ ] 可行性过滤只使用实验前可知的信息
- [ ] 并列规则和随机种子已固定

## Query 固定之后

- [ ] 保存 `query_ids`、模型版本、预测和采集分数
- [ ] 才调用 Oracle 取得 `selected_y`
- [ ] 失败实验保留记录，不无痕删除
- [ ] 新标签只加入下一轮已标注集
- [ ] 外部测试集不进入候选池或训练集

## 策略比较

- [ ] Random 使用相同初始集和预算
- [ ] 所有策略使用相同种子集合
- [ ] 没有只展示有利于主动策略的一次运行
- [ ] 离线全局最优只用于评价，不用于选点
- [ ] 结果明确标为公开数据回放或人工教程

最简单的代码审计方法：在 `query_ids` 赋值之前搜索 `y_pool`。如果出现，必须逐行说明为什么不会影响选样；不能说明就视为泄漏。
