# 主动学习统一实验协议

Unit 04 是单次种子的闭环机制练习：必须遵守下面的权限分离和逐轮记录，
但不作为正式策略优劣证据。Unit 05 起的正式策略比较必须遵守完整协议。

## 三个权限模块

```text
policy：只接收已标注的 X/y、候选 X 和候选 ID，返回 selected ID
oracle：只接收已经固定的 selected ID，返回该候选的新标签
evaluator：一轮或整次 campaign 完成后，计算 regret、测试误差等指标
```

`policy` 不应接收完整 `y_pool`。离线教程虽然必须在内存中保存隐藏答案，
也要通过函数参数把选样、标签返回和事后评价分开，不能依赖“我保证不偷看”
这种人工约定。

## 固定不变的条件

- 同一候选池和目标方向；
- 同一初始已标注样本；
- 同一新增标签总预算；
- 同一 batch size；
- 同一随机种子集合；
- 同一代理模型超参数；
- 同一评价时间点；
- 同一可行性和成本约束。

只改变正在研究的模块。例如比较采集函数时，不同时更换代理模型。

## 必须保存的逐轮字段

| 字段 | 说明 |
|---|---|
| `run_seed` | 初始化与随机策略种子 |
| `strategy` | Random、UCB、EI 等 |
| `round` | 第几轮 |
| `candidate_id` | 被选择候选 |
| `prediction_mean` | query 前的预测均值 |
| `prediction_std` | query 前的不确定性或分歧 |
| `acquisition_score` | query 前采集分数；Random 可为 `NaN` |
| `observed_y` | query 固定后 Oracle 返回的标签 |
| `model_version` | 模型与配置版本 |

材料发现/优化任务另外保存：

- `best_so_far`：更新后的当前最好值；
- `simple_regret`：若离线全局最优已知，由 campaign 后 evaluator 计算。

全局模型学习任务另外保存固定测试集 `mae/rmse/r2` 或校准指标。测试标签
只能由 evaluator 读取，不能进入候选池、模型训练或采集函数。

## 最低基线

- 每项比较至少包含同预算 Random，判断主动选择是否超过随机；
- 研究探索/利用时加入 Greedy，判断探索是否真的有价值；
- 研究复杂代理模型时加入一个简单 GP/RF，判断复杂度是否必要；
- 不相关的基线不必机械加入，但省略原因要在配置中说明。

## 统计要求

Unit 05 起：

- 预先声明多个初始化种子；
- 报告每轮均值、标准差或置信区间；
- 展示全部学习曲线，而不是只挑最好一次；
- 材料发现/优化任务至少报告 best-so-far 和 simple regret；当研究目标是
  找回一组优质候选而非单个最优点时，再报告 top-k 命中；
- 全局模型学习任务至少报告固定测试集 MAE 或 RMSE；只有代理模型输出了
  可解释的预测分布或区间时，才额外报告覆盖率、NLL 等校准指标。

不同目标不机械共用全部指标。报告必须说明主指标、辅助指标以及省略某项
指标的原因。

## 结论模板

可以写：

> 在本公开候选池、固定预算和预声明种子下，UCB 的平均 simple regret 低于 Random。

不能写：

> UCB 对所有材料都最好。

更不能写：

> 模拟结果证明该候选粘合剂已具有高性能。
