# Unit 06 概念精讲：批次不是把单点排序截前几名

## 1. 批量主动学习

一次选择 \(b>1\) 个候选能并行实验，但同一批的候选尚未返回标签，模型不能在批内逐点真实更新。

## 2. 冗余

若高分候选聚集在同一区域，top-b 可能重复获取相同信息。多样性项鼓励覆盖不同区域。

## 3. 可行性

可行性可包括：

- 组分比例和为指定范围；
- 温度、压力和时间在设备窗口；
- 原料可获得；
- 安全、法规和相容性要求；
- 候选没有重复实验。

这些规则不依赖隐藏性能，因此可以在 query 前使用。

## 4. 成本

简单成本感知分数：

\[
a_{\text{cost}}(x)=\frac{a(x)}{c(x)}
\]

但低成本不应无限主导，必须结合科研目标和最小信息价值。

## 5. 失败实验

失败可能是重要标签：不可制备、设备失败、测量低于检出限。记录 `status`、失败原因和是否可重试，不能只保留成功样本。

## 6. 人工审核

算法推荐状态应为 `proposed`，化学组审核后才变为 `approved`。排名不是实验指令。
