# Unit 04 概念精讲：循环、状态与日志

## 1. 初始化

初始已标注集可以随机、空间覆盖或由专家选择。忠实复现论文时服从论文；公平比较时所有策略必须使用相同初始集。

## 2. 训练与预测

第 \(t\) 轮：

\[
\text{model}_t \leftarrow \operatorname{fit}(\mathcal{D}_t)
\]

候选预测必须只依赖 \(\mathcal{D}_t\) 和候选特征。

## 3. Query

\[
x_t^*=\arg\max_{x\in\mathcal{P}_t}a_t(x)
\]

选中后，Oracle 返回 \(y_t^*\)，并更新：

\[
\mathcal{D}_{t+1}=\mathcal{D}_t\cup\{(x_t^*,y_t^*)\}
\]

## 4. 停止条件

- 标签/实验预算耗尽；
- 达到目标性能；
- 候选池为空；
- 连续多轮没有改进；
- 实验安全或设备条件要求停止。

正式实验应预先定义停止规则，不能因为某策略暂时领先就提前结束。

## 5. 日志

query 前保存预测和采集分数，query 后保存 Oracle 返回。日志是复现证据，不是可选装饰。

## 6. 离线评价

离线完整数据允许在评价阶段计算全局最优和 regret；真实实验通常不知道全局最优，只能报告 best-so-far、目标达成和实验成本。
