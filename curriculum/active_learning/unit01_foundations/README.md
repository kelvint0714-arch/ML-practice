## 今天为什么学

普通监督学习问“怎样根据已有标签训练模型”；主动学习多问一步：“下一个昂贵标签应该向谁请求？”如果不先分清已标注集、候选池、采集函数和 Oracle，后面看 GP、随机森林或 GNN 时会误以为模型名称就是主动学习算法。

## 核心概念

```text
材料表示
→ 代理模型
→ 预测均值与不确定性
→ 采集函数选择 query
→ Oracle 返回标签
→ 加入已标注集并循环
```

主动学习可以服务两个不同目标：

- 全局模型学习：用更少标签降低整体预测误差；
- 材料优化：用更少实验找到性能最优候选。

目标不同，采集函数和评价指标也不同。

## 分步骤任务

1. 给已标注集、候选池和固定测试集分别画框。
2. 标出 query 固定前后标签权限。
3. 使用固定预测均值和标准差计算一次 UCB。
4. 只根据采集分数选候选编号。
5. query 固定后才调用教学 Oracle。
6. 使用同预算随机选择做对照。
7. 说明这只是已有标签上的回放。

## 核心代码骨架

```python
ucb_score = prediction_mean + beta * prediction_std
query_position = np.argmax(ucb_score)
query_id = pool_ids[query_position]

# 标签揭示线：query_id 固定后才允许调用。
observed_y = oracle(query_id)
```

## 常见错误

| 错误 | 后果 | 正确处理 |
|---|---|---|
| query 前查看 `y_pool` | 选样答案泄漏 | 固定 ID 后才揭示 |
| 把 RF 称为主动学习 | 模块混淆 | RF 是代理模型 |
| 只与旧模型比较 | 无法判断选样作用 | 加同预算 Random |
| 把查表称为实验 | 证据等级错误 | 写“离线回放” |
