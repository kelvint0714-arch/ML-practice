# Unit 01 参考答案

## 练习 1

- 表示：ECFP、GNN embedding；
- 代理模型：随机森林；
- 不确定性：树间标准差；
- 采集函数：UCB；
- Oracle：拉伸强度实验。

GNN 也可以直接充当代理模型，取决于它输出 embedding 还是最终预测。

## 练习 2

\(\beta=0\) 时 UCB 等于均值：D=5.0、E=4.5、F=5.2，选择 F。

\(\beta=1\) 时：D=5.3、E=5.6、F=5.3，选择 E。增大 \(\beta\) 提高探索权重。

## 练习 3

`best_pool_value` 来自隐藏候选标签，并用于调 `beta`，因此选样间接看到了答案。`beta` 必须在查看 `y_pool` 前固定。

## 练习 4

公开数据回放能验证代码的闭环、标签权限和离线样本效率。它不能证明算法已在新材料实验中成功，也不能证明推荐候选可制备或安全。

## 练习 5

正确顺序：

```text
已标注集 → 模型 → 候选预测 → 采集分数 → 固定 query
                                           │
                                      标签揭示线
                                           ↓
                                   Oracle → 更新数据
```
