# Unit 01 概念精讲：从监督学习到主动学习

## 1. 普通监督学习

已有一批 \((X, y)\)，模型学习从输入到目标的映射。训练完成后，研究者通常被动接受已有数据。

## 2. 主动学习

数据标签昂贵，但候选特征可以提前得到。模型每轮从未标注候选中选择最值得获取标签的样本：

\[
\mathcal{D}_{t+1}=\mathcal{D}_t\cup\{(x_q,y_q)\}
\]

其中 \(x_q\) 由采集函数选择，\(y_q\) 由 Oracle 返回。

## 3. 贝叶斯优化与主动学习

贝叶斯优化常把“尽快找到最大/最小值”作为目标；主动学习也可把“尽快学准整个函数”作为目标。两者共享代理模型、预测不确定性和采集函数，但研究问题必须先写清。

## 4. 五个模块

| 模块 | 回答的问题 | 例子 |
|---|---|---|
| 表示 | 材料怎样变成数字？ | 配方特征、ECFP、GNN embedding |
| 代理模型 | 做实验后性能大约多少？ | GP、RF、MLP、GNN |
| 不确定性 | 模型哪里没把握？ | GP 方差、集成分歧 |
| 采集函数 | 下一次选谁？ | Uncertainty、UCB、EI |
| Oracle | 谁返回真实标签？ | 查表、DFT、实验 |

## 5. 三个数据区域

| 区域 | 特征 | 标签 | 用途 |
|---|---:|---:|---|
| 已标注集 | 可见 | 可见 | 训练 |
| 候选池 | 可见 | query 前隐藏 | 等待选择 |
| 固定测试集 | 可见 | 只在评价时使用 | 比较全局模型 |

优化任务可以在离线评价阶段使用全局最优计算 regret，但这个答案不能参与 query。

## 6. Oracle 的证据等级

```text
人工函数 < 公开完整数据查表 < 数值模拟/DFT < 真实下游任务实验
```

低等级 Oracle 适合调试算法，高等级 Oracle 才能支持材料结论。不能因为代码里调用了 `oracle()` 就声称仪器已经完成实验。
