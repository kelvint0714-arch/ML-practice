# 本地学习输出

这个目录只用于保存学习者自己运行课程时产生的笔记、CSV、JSON 和图片。
除本说明外，目录内容默认被 Git 忽略，不属于课程发布资产，也不代表仓库维护者完成了任何研究实验。

推荐按课程编号建立目录，例如：

```text
learning_outputs/
├── day02_metrics/
├── day13_fair_comparison/
└── active_learning/
    └── unit01_foundations/
```

每次学习至少记录：

- 输入数据或人工例子；
- 执行的步骤；
- 输出和检查结果；
- 自己的解释；
- 当前结论能说明和不能说明什么。

不要在这里放 API key、未授权数据、大型缓存或真实项目机密。
