# 机器学习零基础词典

本词典只给出当前课程需要的直观含义。公式和严格定义在对应 Day 中逐步补充。

## 数据

| 术语 | 直观解释 | 本项目中的例子 |
|---|---|---|
| 样本 | 数据表中的一行、一个要学习的对象 | ESOL 中的一个分子；未来可能是一条粘合剂测量记录 |
| 特征 | 模型看到的输入数字 | 1024 维 ECFP、配方比例、固化温度 |
| 标签/目标 | 希望模型预测的答案 | ESOL 的 `logS`；未来可能是搭接剪切强度 |
| `X` | 多个样本的特征矩阵 | shape 通常为“样本数 × 特征数” |
| `y` | 每个样本对应的目标数组 | 回归中通常是一维 shape |
| 训练集 | 允许模型学习的数据 | 调用 `fit()` 时使用 |
| 验证集 | 选择模型和参数的数据 | 比较候选模型，不参与训练 |
| 测试集 | 方案冻结后的最终检查 | 不能每天反复查看 |
| 候选池 | 主动学习中暂时没有使用标签的样本 | 等待模型选择的下一批实验候选 |

## 模型动作

| 术语 | 直观解释 |
|---|---|
| `fit` | 让模型根据训练输入和训练标签学习参数 |
| `predict` | 用已经训练的模型对输入产生预测 |
| 参数 | 模型从数据中学到的内部数值，例如线性权重 |
| 超参数 | 训练前由人设置的选项，例如树深、正则强度 |
| 基线 | 用来判断复杂方法是否真的有价值的简单参照 |
| 过拟合 | 训练数据表现很好，但新数据表现明显变差 |
| 欠拟合 | 模型过于简单，训练和验证表现都不好 |
| 泛化 | 模型在没有参与训练的数据上仍然有效 |

## 验证与防泄漏

| 术语 | 直观解释 |
|---|---|
| 数据泄漏 | 训练过程通过不合理途径看到了验证或测试信息 |
| K 折交叉验证 | 把训练数据轮流分成训练折与验证折 |
| OOF | 每个训练样本由“没见过该样本”的折模型产生预测 |
| random split | 随机把样本分到不同集合 |
| scaffold split | 按分子骨架分开，更严格地检验结构泛化 |
| 随机种子 | 固定伪随机过程，便于复现 |
| 均值 | 多次实验结果的平均水平 |
| 标准差 | 多次实验结果波动的大小 |

## 传统模型

| 模型 | 一句话理解 |
|---|---|
| Dummy | 不学习复杂规律的最低参照 |
| Ridge | 带 L2 正则的线性回归 |
| 决策树 | 通过一连串“如果……那么……”切分数据 |
| 随机森林 | 多棵有随机差异的树投票或平均 |
| Gradient Boosting | 后一棵树逐步修正前面模型的错误 |
| SVM/SVR | 用间隔和核函数建立分类或回归边界 |

## 神经网络

| 术语 | 直观解释 |
|---|---|
| 神经元 | 接收输入、做加权求和并经过激活的计算单元 |
| 层 | 一组并行神经元 |
| MLP | 多层全连接神经网络 |
| 激活函数 | 给网络加入非线性，例如 ReLU |
| 前向传播 | 输入从第一层流到输出，得到预测 |
| 损失函数 | 衡量预测与真实答案的差距 |
| 优化器 | 根据损失调整模型参数的方法 |
| Batch | 一次用于更新参数的一小批样本 |
| Epoch | 训练数据大致完整经过模型一次 |
| 学习率 | 每次参数更新步子的大小 |
| 早停 | 验证表现长期不再改善时停止训练 |

## 结合与实验推荐

| 术语 | 直观解释 |
|---|---|
| Stacking | 把多个基础模型的预测交给第二层模型组合 |
| 混合模型 | 让传统模型和神经网络在同一流程中互补 |
| 消融实验 | 去掉一个组件，检查改进是否真的来自它 |
| 不确定性 | 模型对某个预测有多不确定的估计 |
| 主动学习 | 模型根据不确定性或其他准则选择下一批标注/实验 |

## 图神经网络

| 术语 | 直观解释 |
|---|---|
| 节点 | 图中的对象，例如原子 |
| 边 | 节点之间的关系，例如化学键 |
| 节点特征 | 描述节点的数字 |
| 消息传递 | 节点接收并聚合邻居信息 |
| Readout/池化 | 把所有节点表示合成整张图的表示 |
| GCN | 按图连接关系聚合邻居的基础图网络 |
| GraphSAGE | 学习怎样聚合采样到的邻居 |
| GAT | 用注意力权重区分不同邻居的重要性 |
| GIN | 对图区分能力较强的图同构网络 |
