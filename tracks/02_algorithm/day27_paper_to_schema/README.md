# Day 27：从直接相关论文映射到粘合剂数据字段

> 状态：待学习。今天只做来源可追溯的字段映射，不把不同论文数据拼成训练表。

## 今天为什么学

数据模板中的每一列都应有明确用途，
但“论文出现过某字段”不等于“所有粘合剂都必须填写该字段”。

今天核对三篇直接研究 AI 预测粘合剂性能的论文，
学习把论文中的输入、输出和实验条件映射为候选字段。

三篇论文分别研究环氧、环氧结构胶和聚氨酯木材粘接。
它们能帮助设计框架，
却不能因目标都叫“强度”就直接合并数值。

## 核心概念：已核验的三篇直接论文

### 论文 A：小数据环氧胶主动学习

Pruksawan et al. (2019)，DOI：
<https://doi.org/10.1080/14686996.2019.1673670>

- 材料体系：双酚 A 环氧树脂与聚醚胺固化剂；
- 主要输入：环氧树脂分子量、固化剂分子量、胺/环氧比例、固化温度；
- 目标：受控单搭接剪切试验中的接头强度；
- 方法启示：小数据、梯度提升和逐轮主动学习。

### 论文 B：环氧结构胶神经网络

Kang et al. (2021)，DOI：
<https://doi.org/10.3390/nano11040872>

- 材料体系：包含多种配方组分的环氧结构胶；
- 主要输入：树脂、核壳橡胶、柔性剂、稀释剂、填料、促进剂、固化剂、催化剂用量；
- 目标：室温搭接剪切强度与低温冲击剥离强度；
- 方法启示：配方比例到多个性能目标，但论文分别建立预测任务。

### 论文 C：聚氨酯木材粘接

Schubert and Kläusler (2020)，DOI：
<https://doi.org/10.1007/s00226-019-01144-6>

- 材料体系：单组分聚氨酯预聚物与山毛榉木材；
- 主要输入：预聚物组成/结构参数与不同预处理条件；
- 目标：粘接木材的拉伸剪切强度；
- 方法启示：材料组成之外，基材和预处理同样会影响标签。

## 输入—输出映射

| 映射层 | 论文 A | 论文 B | 论文 C |
|---|---|---|---|
| 体系 | 环氧/聚醚胺 | 多组分环氧结构胶 | 1C 聚氨酯/木材 |
| 配方输入 | 分子量与配比 | 8 类组分用量 | 预聚物组成参数 |
| 工艺输入 | 固化温度 | 固化与制样条件 | 预处理/环境条件 |
| 基材 | 受控金属接头 | 钢基材 | 山毛榉木 |
| 预测目标 | 搭接接头强度 | 剪切与冲击剥离 | 拉伸剪切强度 |
| 学习重点 | 小样本主动学习 | ANN 配方预测 | 多算法比较 |

## 哪些字段可以保持通用

这些是“字段类别”通用，不代表数值可混合：

- 样品编号、粘合剂体系、组分身份与用量；
- 固化条件、基材、表面处理与胶层厚度；
- 测试方法、环境、性能值、单位、重复、批次与来源。

## 哪些字段必须按体系专门定义

- 环氧当量、胺/环氧比和环氧特定组分类别；
- 聚氨酯 NCO、预聚物参数、木材含水率与预处理；
- 低温冲击剥离等专用测试条件。

如果最终研究体系不是环氧，
不能强迫化学组填写环氧专用字段。

## 为什么三篇数据不能直接拼接

三篇在化学体系、基材、配方变量、制样过程、测试方法、
测试温度、单位和标签物理含义上均可能不一致。
直接纵向拼接会让模型识别论文或材料类别，
而不是学习可靠的粘合剂规律。

## 分步骤任务

1. 逐篇记录体系、输入、条件、目标和测试方法。
2. 把字段分为通用类别与体系专用项。
3. 标出三篇论文之间不可比较的标签。
4. 对照 v0.3 记录待删、待改名和待补字段。
5. 把所有体系选择问题交给化学组确认。
6. 只保存字段依据，不下载拼接论文结果数值。

## 只解释今天新增的语法

- YAML 用缩进表达从属关系，不使用 Python 括号。
- `key: value` 表示一个字段名和字段值。
- `- item` 表示列表中的一项。
- `false` 是布尔值，表示默认不允许公开上传。
- `draft-v1.0` 表示讨论稿，不代表已经冻结。
- DOI 只记录文献依据，不代表取得了可训练原始数据。

## 需要化学组回答

化学组需要确认：粘合剂体系、首要预测性能、
每行代表配方/试样/重复中的哪一种、可提供的配方和工艺字段、
测试条件是否统一，以及哪些数据可建模或公开。

## 常见错误

| 错误 | 后果 | 正确处理 |
|---|---|---|
| 把论文字段全设为必填 | 体系不适配 | 先确认研究边界 |
| 把三篇强度纵向拼表 | 标签不可比 | 分体系、分任务 |
| DOI 等于公开数据 | 误判可用性 | 单独核查数据许可 |
| 不记录测试条件 | 标签含义不清 | 条件与性能一起存 |
| 论文结果当本组结果 | 证据归属错误 | 只写作方法依据 |
